# s0f 术语提案与存疑记录（fable 车道）

## batch 1

- 批次 1 / id 6154, 6172, 6210 等 / 原文关键词：職員室 / 建议译法：教员室 / 理由：active.json 未覆盖；本批统一取「教员室」。全篇多章出现（探索地图点、`png/select` 地图点名也有烤字），且 CLAUDE.md 地图点列表含「職員室」，建议纳入 glossary 定译，避免各章在「教员室／教务室／办公室」间漂移。
- 批次 1 / id 6351 / 原文关键词：扁桃体 / 建议译法：杏仁核 / 理由：日语「扁桃体」＝脑部 amygdala，中文若照搬「扁桃体」会误读为咽喉扁桃腺（假朋友词）。本批已译作「杏仁核」；该词与 6350 的「海馬→海马体」「海馬傍回→海马旁回」、6351 的「内嗅皮質→内嗅皮质」同属脑科学术语组，s0f/s7f 等复现处应整组定译。
- 批次 1 / id 6359, 6361, 6369 / 原文关键词：数日間の逆向性健忘 / 建议译法：波及数日的逆行性遗忘 / 理由：「数日間」修饰的是丢失记忆的时间跨度而非病程时长，「为期数日」易误读为"遗忘只持续几天"。本批统一用「波及数日的」，此短语在 6359/6361/6369/6370 成句族复现，后续批次（含 crd、s7f 复述处）建议沿用同一措辞。
