## 二、需要查证才能裁的 12 条

其余 221 条是量词/语序/去被动/补主语一类的常规改动，照收。下面这些不是。

### 查实后确认模型判对（3 条）

- **8778 — 真错译，本 SEG 唯一一条。** `【お母さん】「はいはい、彩野、直哉さん、お帰りなさい」`
  上一行 8777 是「我按下彩野同学家的门铃」——所以 `はいはい` 是应门铃的**「来了来了」**，
  opus 的「好了好了」取了敷衍/应付义。fable-wf 主动 `adjudicate=true` 报上来。
  **这是 handoff「撞上疑似错译/错字一律请裁」条款第一次在生产里兑现**（该条款的有效性
  此前只有准入小考的 run1/run2 对照支持，见 handoff）。
- **9126 — `style.md:208` 逐字支持。** 该条把 `这一侧` 锁给 s8 高潮句族与场景名位
  （16799／16794 成对，绑定冻结卡 113），日常位作 `这一边`。本行是日常位。
- **8990 — v13 ⑥ 支持。** `交流 → 来往` 是 v13 正式裁定，fable-wf 为避开中文同形碰撞
  而把 `コミュニケーション` 译作「沟通」，理由成立。

### 查实后否掉模型（1 条，用户复核后 2 条改判）

- **10026 — 控制会话建议 keep_opus，用户改判 adopt。**
  `【ユウイチ】「空、飛べるかな？」`（坠落前的枢纽句）。控制会话的理由：下一行 10027
  アヤノ答「怎么可能**飞得起来**啊」，与 opus 的「能**飞起来**吗」成对，改「飞得上去」
  会断掉这对回声。用户裁定采纳 fable-wf 的「飞得上去吗」——**10027 未在本轮队列中，
  该回声现已不成对，后续 SEG 或复盘时值得重看。**
- **8920 / 9672 — 控制会话建议 keep_opus。** 8920 用户改判 adopt（`本当は`→「说真的」）；
  9672 用户维持 keep_opus（`棒`→`美` 会与下句「很漂亮的不是嘛」重复，opus 用「棒」
  正是为避重）。

### 改写（3 条，两个通道各对一半）

- **9126** → 「那也许是因为，老师是站在学校这一边的人。」
  `身を置く` 的地道中文是「站在……这边」，opus 的「把自身放在……这一侧」是日语句式搬运。
  **讨论要点（用户提出、经讨论保留原状）**：本句有一层言外之意——由加里作为"学校这边的人"
  已与当年拉开距离。但**直哉在此刻并不知道由加里与ユウイチ的关系**（e1／s7f 才揭），
  这层意思是**重读才成立**的反讽，且正由这句话的"说不清楚"承载。若在译文里外化，
  等于让直哉说出他还不可能知道的判断，反讽尽失。故只改句式、不动含混度。
- **9620** → 「【サクラ】「虽说是推理，其实也就是点心理学之类的东西」」
  ds-flash 丢了 `ちょっとした`，fable-wf 把 `ちょっとした` 错挪去修饰"像"。
- **10071** → 「我把从在走廊上看见ユウイチ、一直到上了天台为止的经过，说明了一遍。」
  ds-flash 丢掉 `来る` 的位移义，fable-wf 的「到来到」两个「到」相撞。

### 需要新开 glossary 条目（1 条）

- **9014 `僕にもその答えはわからないのだから。`** —— adopt fable-wf「因为连我自己，
  也不知道那个答案。」
  **v13『わからない』二分只裁了「不理解位→不明白／不知所措位→不知道」，没有覆盖
  "宾语是具体名词的知识位"。** 本行宾语是「答え」，中文「不明白答案」不成搭配
  （他是不知道答案，不是听不懂答案）。
  ⚠ **代价**：9010/9011/9017/9139 是同一句族（都在讲"为什么我没在故事里登场"），
  全部作「不明白」；9139 更是明写 `『僕にもわからない』`→「『我自己也不明白』」。
  9014 改后与该族不再同形——**但日文本身也不同形**（9014 多一个宾语 `その答え`），
  故可接受。**建议 v15 补第三支判据**，否则后续 SEG 遇到同型会再撞一次。
