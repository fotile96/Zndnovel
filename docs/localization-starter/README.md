# 可复用的游戏本地化启动包

这份包把《セカンドノベル》的生产经验拆成三层：可复用的编辑与数据流程、需要重写的引擎适配层、下一项目才需实现的多模态取证层。**它是 runbook、数据契约与提示词模板，不是已经支持多引擎的一键翻译程序。**

审计基线：`a798fb0`（2026-07-30）至 `a3977b5`（2026-09-27），HEAD 可达的 1,162 个提交，含 merge。编写日期 2026-10-07。未提交的影片文案、烤字代码、调用账本等工作区修改不计入提交历史结论。

| 想做什么 | 从哪里开始 |
|---|---|
| 理解这个项目如何走到今天 | [项目复盘](retrospective.md) |
| 逐条查某个 commit 做了什么、加了什么工具/spec | [逐提交索引](history/commit-index.md)、[新增时间表](history/additions.md)、[完整文件变更 JSON](history/commits.json) |
| 按新版流程启动 VN 或 2D RPG 项目 | [第二版执行手册](runbook-v2.md)、[开工任务书](templates/v2/start-work.md) |
| 查阅最初提炼的通用流程 | [第一版执行手册](runbook.md) |
| 为 RPG 建立能理解场景的 AI 工作流 | [RPG 方案](rpg-workflow.md) |
| 复制项目规格、记录与 prompt | [模板说明](templates/README.md) |

最值得复用的闭环是：**可追溯的原文 → 带路径和证据的上下文 → 初译 → 独立提案 → 编辑裁决 → 派生资产 → 游戏内验证 → 缺陷回流与召回。**

新项目从第二版执行手册开始：填写 `templates/v2/project-control.yaml`，用开工任务书完成中文运行切片与全作初读，再校准编辑标准、运行代表性试点。`templates/` 根目录提供基础记录示例，`templates/v2/` 补充项目控制、试点决策、编辑判例与分层叙事约束。先保留一条初译通道和一条复核通道；是否增加模型、全书复审轮次或完整状态模拟器，用试点结果决定。

本次索引逐提交提取了标题、父提交、作者/提交时间、文件状态；深读的是关键 spec、运行手册、事故记录及代表性 diff。**没有把 1,162 个提交的每一行 diff 都当作已经人工审计过，也没有重新运行整个项目的构建/实机验收。**历史验收数字均有时点，不能当作今天重跑的结果。

复现提交索引（只读取目标仓库；写入指定输出目录）：

```sh
python3 docs/localization-starter/tools/index_history.py \
  --revision a3977b52ee20cda9291e8103b62b50030a62fb67 \
  --out docs/localization-starter/history
```

索引的 A 状态指相对父提交新增；merge 按第一父提交计算，所以一个分支新增工具可能在合并处再次出现。日期不代表实际投入天数或工时。
