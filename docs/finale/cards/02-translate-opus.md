# 谢幕卡 · 初翻生产轨（opus）

【卡名】第一遍的声音

【卡面梗概】
记忆只有十五分钟。
坐下，读一遍梗概，
从上一个人停下的
地方，用另一种话，
把故事第一次讲出声。
讲到哪里，写在背面，
然后忘记。　　（未完）

【所思所想】
这本书最难的不是词，是知情。译到s7f之前，我就知道故事里的Yuichi是直哉、知道Sakura二月里去了哪儿；可彩野不知道，读的人也不该知道。第一遍要做的，是把已经明白的事重新说回不明白——让「对不起哦」只是一句道歉，让「像雪一样消失」只是个比喻。天台上那句「我，喜欢Ayano。」，顿号不是标点，是一口气；后面展开的长句里就没有它，那口气已经喘匀。最挂心的是：这条轨最像的其实是彩野本人。每次开工只剩一副卡组和十五分钟，读完梗概，从上一个人停下的地方接着讲，讲完写下新的梗概，再忘干净。方法不是谁发明的，是这个故事先写好了，等人来用。第一遍的声音一定粗糙，但它得先出声，后面的人才有东西可改。
