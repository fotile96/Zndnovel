### 4. 逐批登记的判断点

- **12390 `セクション４のあと、階段のウワサという形で物語は続いたが――`**：`階段のウワサ` 是**章节３**的内容，原文写「セクション４のあと」在剧情上讲不通（疑为原作笔误，应为セクション２）。**照原文直译，未修复**（同 CLAUDE.md「两封信字面不同不要修复」的处置）。→ **请派发方复核是否需要发 patches。**
- **12595/12597 `『最低』` / `さいてい？……最低？`**：原文用**假名→汉字**两段式表现"先听到音、再认出词"，中文无从复现该字形装置。译作『差劲透了』＋「差劲透了？……差劲透了？」，**只剩重复、丢了两段式**。第二行**未给第二次出现补『』**（虽然 12595 近旁有先例、满足 style.md v7 (a) 条，但不补也成句，按"两者不必则不补"从严）。→ 疑点，见 §5 提案 3。
- **12639 `【千秋】「はい」`**：车道内已有两形——7228「是」（应答陈述）／10511「好的」（应承提议）。本行 直哉 说的是提议（"你看电视或者玩游戏都行"），故取**「好的」**，据此吃下一条对 7228 的 W4。见 §5 提案 2。
- **12433 `……雷？`**→**「……雷声？」**：前一行 12432『……この音は……。』把话题锁在"声音"上，中文裸作「……雷？」不成句。（顺带把 W3 从超限压回阈值内，但取词理由是句法，不是 W3。）
- **12536–12540 `銀婚式`**→**银婚纪念**（首次出现，全库无先例）。理由：中文没有「银婚式」这个词形，而 12537 千秋 只截取前半 `ぎんこん` 反问，作「银婚……？」正好落在「银婚纪念」的前两字，段子结构完整保留。→ 见 §5 提案 4。
- **12547 / 12566 / 12571 / 12724** 旁白内引语的 `「」` 原样保留（原文即用「」而非『』）。
- **12659 `久しぶりにアレでも、してみようかな……`**：`アレ` 是片假名强调，中文作**「那个」不加引号**——按 style.md v7 补『』口径，此处 (a)(b) 均不满足。原文行尾无句号，译文同样以「……」收尾。
- **12660/12663/12666** 数数行的**全角数字与 `_n` 位置逐条对齐原文**（３……_n２……_n１……。／１、_n２、_n３……_n…／２０、_n２１……。）。
- **12626 `大雨洪水暴風波浪警報`**→**「大雨洪水暴风波浪警报」**：逐字对译而非改用中文气象规范词（暴雨/大风/巨浪），因为**下一行 12627 的笑点正是"汉字太多看不懂"**，换成规范词会拆掉这个包袱。

### 5. 术语提案（留给术语委员会）

1. **`苦手` 建议进「按义二分词」表**：默认读**不擅长**（技能/应对，7222/10693/11794）；另一读**害怕**（对象是恐怖或生理性厌恶物，11658、本批 12714 `雷は苦手`）。判据：主语能否"练好"——能练好的取"不擅长"，练不好的取"害怕"。
2. **`【千秋】「はい」` 的分治口径**：肯定/确认前句→**「是」**（7228 型）；应承对方提议/许可→**「好的」**（10511 型）。本批 12639 走后者。建议正式登记，否则每次出现都会产生一条不可消除的 W4。
3. **`最低`（女性感叹词）→ 建议登记为「差劲透了」**（本批首次出现，12595/12597）。同时登记：**12597 的假名→汉字两段式装置中文放弃复现**，如委员会另有方案（如"最差劲？……是说『最差劲』？"）请回改。
4. **首次出现、建议登记的一般名词**（全库此前无译例，本批定形）：`銀婚式`→**银婚纪念**（12536/12538）｜`シュノーケル`→**呼吸管**（12668/12670）｜`ココア`→**可可**（12507「热可可」）｜`雨宿り`→**避雨**（12449/12451/12453）｜`停電`→**停电**（12684/12687/12690）｜`懐中電灯`→**手电筒**（12696/12697）｜`湯船`→**浴缸**（12651/12661/12665/12669）｜`脱衣所`→**更衣间**（12703）｜`換気扇`→**排气扇**（12676）｜`変電所`→**变电站**（12686）｜`乾燥機`→**烘干机／烘干**（12512/12554）｜`熱海`→**热海**（12542）｜`出前`→**外卖**（12531）｜`風物詩`→**（夏天的）一景**（12700）。
