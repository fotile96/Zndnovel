## batch 5

### 1. 『あらすじ』を作成する → 制作『梗概』（**动词缺口，优先级最高**）
- id 11：`物語の続きを聞くには、新しい『あらすじ』を作成する必要があるかもしれない。`
- 现状：glossary v6 只定了名词「あらすじ→梗概」，**没有定「作成する」的动词**
- 建议：**制作『梗概』**（不用「写／整理／编写／创建」）
- 理由：这个动宾搭配是全游戏出现频次最高的机制句之一——196 个 crd 脚本每个结尾都有 `oCard.show(…, "『…』のあらすじを作成しました。")`，fragment_main 还有顺序约束提示「あらすじは物語の先頭から順番に作成する必要があります」。名词已锁而动词未锁，等于把最高频的复现句族留给各批各译。选「制作」的依据：游戏内该动作是"解谜后得到一张卡"，是 UI 动作而非写作动作；而"写"会与直哉在名片背面手写的具体动作抢词（那里该用"写"）。本批 id 11 已按「制作」译。

### 2. ■Ｔｉｍｅ ｏｖｅｒ 原样保留（沿 batch 4 提案 2 的形态判据，但需确认外延）
- id 12、18：`■Ｔｉｍｅ ｏｖｅｒ`（■ + 全角拉丁 + 半角空格，字面 `■` + FF34.. + 0x20 + ..FF52）
- 处理：**逐字原样保留**，未加中文
- 理由：本车道 batch 1/4 已按"全角拉丁形态原样保留"处理『Ｓｔｏｒｙ』『ｌｉｂｒａｒｙ』『Ｆｒａｇｍｅｎｔ』『ｍｅｍｏｒｙ』；CLAUDE.md 亦记「既有官方英文…可保英文大词」。
- ★待裁决：batch 4 提案 2 的通则是按"**菜单按钮名**（图片轨烤死）"立的，而 Ｔｉｍｅ ｏｖｅｒ 不是按钮，是**消息窗内的画面标题**，图片轨没有对应素材，理论上可以中文化（如「■时间到」或「■Ｔｉｍｅ ｏｖｅｒ（时间到）」）。请术语委员会明确通则外延覆不覆盖这类"非按钮的英文大词"。本批按保守（原样）处理，改动成本极低（全局仅 2 行）。

### 3. 記憶が途絶える → 记忆中断（TIMEOVER 系统句，建议锁定）
- id 10、16：`彩野さんから「記憶」が途絶えてしまったようだ。`
- 建议：**「记忆」…中断**（不用「断绝／消失／没了／断线」）
- 理由：①「消える」在本作是专用词（彩野笔记锚句 [248]「１５分で記憶は消える→记忆１５分钟就会消失」、千秋的"消失"句族 [15334-15337]、s0f 前女友的『消えた』[6081] 是一整条互文链），此处若也译"消失"会把两个不同的日文词并成一个中文词，毁掉那条互文；②「途絶える」的语感是"讲述的线被掐断"，不是"记忆没了"——沙漏满的瞬间她并未失去既有记忆，只是话头断了。本批 id 10/16 已按「中断」译。

- 处理：按 style.md「复现句族内逐字一致」，两组译文**逐字同文**
- 提醒后续批次：本函数的收尾分支 `comStorySceneEnd` 三选单（回 Story／去 Fragment／回菜单）若落在别的批次，其措辞需与本批 id 11「制作新的『梗概』」、id 17「选择正确的『日记』」的指路口径对齐。

### 2. 待ち合わせ → 碰面（沿用既有，登记备案）
- id 55：`【アヤノ】「あっ、そろそろ待ち合わせの時間かも」`
- 现状：glossary v6 未收；本车道 forward 已有 7968「离碰面的时间，好像还有相当富余」、7993「碰面的时间虽然近了……」
- 建议：**碰面**（不用「约会／会合／见面」）
- 理由：本作的『放課後の約束』母题里，「待ち合わせ」指的是与「あの子」在教室约定的会面时刻，与「約束→约定」是配套词；译"约会"会误导成恋爱语义（同章明确否认了 アヤノ×ユウイチ 的"约会"说法），译"见面"则与「会う」抢词。本批 id 55 已按「碰面」译。
