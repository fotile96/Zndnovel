# 汉字分级字表（供 `tools/check_charlevel.py` 判定 ruby 注音）

## 为什么有这个目录

`glossary/style.md`「绘本段」节要求用字限**学龄前／小学低年级**，不得已的生僻字用引擎 ruby
注汉语拼音 `<汉字,pīn yīn>`。此前该判定纯靠译者眼力——**实测会漏**：b123 绘本段译者只扫出
4 个候选（绷/妖/霞/熬）就收手，自评「全批用字已压在学龄前／小学低年级范围内，无一处需注音」，
而机械扫描发现文本里另有 囔、勒、渗、逞、漆、跺、蹬、谎、舔、唬 等一批字在表外。

**结论不是译者不用心，是「凭印象判断一个字难不难」这件事本身不可靠。** 故做成工装。

## 文件格式

一行一字，`#` 开头为注释（首两行是表名与字数）。UTF-8。

| 文件 | 字数 | 来源 |
|---|---|---|
| `jiaoyu-jibenzi-300.txt` | 300 | 《义务教育语文课程标准》（2022年版）附录4「识字、写字教学基本字表」 |
| `jiaoyu-changyong1-2500.txt` | 2500 | 同上 附录5「义务教育语文课程常用字表 · 字表一」 |
| `jiaoyu-changyong2-1000.txt` | 1000 | 同上 附录5「字表二」 |
| `gf0025-yiji-300.txt` | 300 | GF 0025-2021《国际中文教育中文水平等级标准》汉字表 一级 |
| `gf0025-erji-600.txt` | 600 | 同上 一～二级累计 |
| `gf0025-chudeng-900.txt` | 900 | 同上 初等（一～三级）累计 |
| `tongyong-yiji-3500.txt` | 3500 | 《通用规范汉字表》（2013年）一级字 |

**取得方式**：经 GitHub 仓库 `zispace/hanzi-chars`（2026-08-04 取，该仓库无 LICENSE，内容为
公开发布的国家标准／课程标准附录字表）转录，再由本目录脚本归一化为「一行一字」。
GF 0025 原表为 3000 字按等级顺序排列，一/二/三级各 300 字且前 900 字互不重复，故按行切片即得各级累计表。

## ⚠ 选型注记：GF 0025 是**二语**标尺，不是母语儿童标尺

`gf0025-chudeng-900` 字数上最接近「刚上小学的孩子约 800 字」这个口径，**但它是给外国人学中文分级的**，
把 `窗 敲 闹 逃 妖 叹 吓 藏 扔 抱 梦` 这类母语小孩很早就认得的字判在表外。b123 绘本段实测：
用它当闸门会把 **74% 的行**判成需注音（表外不同汉字 113/454 = 24.9%），头两名还是妖怪音译名的
`纳×36 / 梅×36`。**不要单独拿它当闸门。**

母语向的一年级识字表（统编版 ~700 字）网上只有图片与付费文档，**未能取得机器可读版本**——
这是本目录已知的缺口，日后若取得应补入并改默认闸门。

## 现行判定口径（用户裁决 2026-08-04）

对绘本段（`scene_s3fc_90`）：

1. **`jiaoyu-changyong1-2500` 打底**——凡不在该表内的字，一律注音（b123 实测 20 字）。
2. **加上**：在 2500 内、但不在 `jiaoyu-jibenzi-300 ∪ gf0025-chudeng-900` 内，
   **且在本段出现次数 < 4** 的字（高频字靠段内重复即可习得，不注）。
3. **排除**句末语气词（`哦 嘛 呀` 一类）。
4. 密度：**每次出现都注**；专名 `纳哈梅` 例外，只在最早出现处注一次。
5. **顺序**：先换更浅的字/词，**换不掉的核心词才注音**（`style.md`：ruby 用于「不得已」时）。

## 已知工装缺口（登记，未处置）

`tools/check_batch.py` 的 W3 显示行宽用 `_max_line_width()` 按**原始字符串**计算，**不剥 ruby**——
`<囔,nāng>` 会被算成约 10 格宽而非 2 格，故译文一加注音 W3 必然虚高误报。
风险：译者见 W3 报警可能删掉 ruby 来消警。
`check_batch.py` 属 P3 段内钉死面（`tools/` + `prompts/`），**段中不得改**，留给开发轨在段边界处理。
