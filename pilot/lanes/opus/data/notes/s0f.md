# 术语提案 · s0f（opus 车道）

> 试点期术语表冻结，本文件只做提案登记，不做裁决。格式：批次 / id / 原文关键词 / 建议译法 / 理由。

## batch 1

### 1. 扁桃体 → 杏仁核（**假朋友，优先级最高**）
- id 6351：`【直哉】「<扁桃体,へんとうたい>、<内嗅皮質,ないきゅうひしつ>」`
- 建议：**杏仁核**（不可照搬汉字「扁桃体」）
- 理由：日文「扁桃体」＝amygdala；中文「扁桃体」＝tonsil（咽部淋巴组织），是标准假朋友。直译会让这句脑区罗列出现一个咽喉器官，读者立刻出戏，且与「海马／内嗅皮质」不在同一解剖层级。本批已按「杏仁核」译出。

### 2. 海馬 / 海馬傍回 / 内嗅皮質 → 海马体 / 海马旁回 / 内嗅皮质
- id 6350、6351
- 建议：海馬→**海马体**（单独出现时；作定语时「海马」）、海馬傍回→**海马旁回**、内嗅皮質→**内嗅皮质**
- 理由：中文神经解剖学通用译名。这四个词与 v6 已定的「顺行性遗忘／逆行性遗忘／情景记忆／程序性记忆」同属一个医学术语族，建议一并纳入词表，避免后续章节（s7f 病情复述段）出现分歧。

### 3. 校庭 / グラウンド 同句并存
- id 6130：`少女が一人、グラウンドを校庭の隅、部室の横のコンクリートの縁から眺めていた。`
- 现状：skeleton/anchors.yaml 15290、16226 已把「校庭」锁为**操场**；本句同时出现「グラウンド」，无处可去。
- 建议：校庭→操场（沿用既有定译）、グラウンド→**场地**（或「运动场」）。本批按「操场角落……眺望着场地」处理。
- 理由：中文只有一个「操场」，两词硬碰。此句是序章唯一冲突点，但 s7f 校庭段可能复发，宜先定口径。

### 4. 直哉クン → 直哉小同学
- id 6177、6210（现任教师对直哉的称呼，片假名「クン」）
- 建议：**直哉小同学**（glossary/voices/naoya.md §2 已列为「酌情」，建议升格为定译）
- 理由：这位教师全场靠拟声词与轻佻语气立人设，片假名「クン」是他把 23 岁社会人当学生逗的标记。若与彩野口中的「直哉君」同形，人物距离感会塌成一层。

### 5. 職員室 → 教职员室
- id 6154、6172
- 建议：**教职员室**（不用「办公室」「教务处」）
- 理由：与后续章节的「保健室／図書室／美術室」等校内地点构成同一命名族（探索场景地图点名亦需成套）；「办公室」会丢掉学校语域。

### 6. 片假名 キオク 的处理约定
- id 6268：`僕は誰かほかの人物のキオクを遠くから眺めているような気分だった。`
- 现状：同段其余各处均写作汉字「記憶」，此处独用片假名，是把「记忆」推远、陌生化的修辞（与本作『物語』『消えた』的引号用法同源）。
- 建议：中文无假名可用，提案统一以**『』引号**承担陌生化功能（本批作『记忆』）。请裁决是否立为通则，或另择手段（如「记忆」加引号 vs 变换词形）。
- 理由：这类"同词异写"在 s7f、e2f 还会出现（如【サクラ】→【ユキノ】的自称表记切换），需要一个可复用的机械规则，否则各批会各自发挥。

### 7. 靴（此处实指上履き）→ 室内鞋
- id 6171：`これからまた頻繁に訪れる事になるのだ。靴ぐらいは買ってしまった方がよいかもしれない。`
- 建议：**室内鞋**
- 理由：紧接 6170 的「下駄箱／スリッパ」，日文「靴」在此语境默认是上履き（校内换穿鞋）。直译「鞋」会让读者以为他要买双外出鞋，逻辑断裂。

## batch 2

### 1. メモ 在 s0f 指的是彩野的手帳（**与现行定译冲突，已知偏离**）
- id 6442：`彩野さんは手にしているメモを僕の方に見せる。`／id 6443：`【彩野】「このメモを私が見て」`
- 现状：`active.json` 定「メモ→字条」；本批这两处的 メモ 与前后文的「手帳」是同一件东西——6444 她当场念的正是手帳第一页的锚句（6347/248），6498「右手の手帳」、6603「手帳は持っているのに」均指同物。
- 处理：本批**按「笔记」译**，故意接受 2 条 W2 警告（check_batch 已记录）。
- 建议：给 メモ 立语境分支——现实层指手帳时作**笔记**；s4s『ポケットのメモ』（口袋里的字条，卡 146）等实体纸片仍作**字条**。若委员会认为不宜分支，请明确指示后续批次一律照「字条」回改。
- 理由：「字条」是本作的关键道具名（ユウイチ 口袋里那张），在序章用同一个词指手帳会误导读者以为出现了第二件物品，且与卡面梗概的用词打架。

### 2. 長期記憶 / 短期記憶 → 长期记忆 / 短期记忆
- id 6406：`長期間の記憶――<長期記憶,ちょうききおく>。`／id 6410：`短期間の記憶――<短期記憶,たんききおく>。`
- 建议：**长期记忆／短期记忆**（备选：长时记忆／短时记忆，为大陆心理学教科书用词）
- 本批处理：ruby 去掉（中文无需注音），用"普通说法――术语"的对举保住原文语感：「长时间的记忆――长期记忆。」「短时间的记忆――短期记忆。」
- 理由：与 v6 已定的「顺行性遗忘／逆行性遗忘／情景记忆／程序性记忆」同属一个术语族，s0f 集中讲解段一次性用齐，建议一并入表定死，避免 s7f 病情复述段各批分歧。

### 3. カード → 卡片（补一条系统词）
- id 6590、6591：`英語の単語カードのように使えば…`／`カードを使えば机の上に広げて一瞥することもできる。`
- 建议：**カード→卡片**、**名刺→名片**、**単語カード→单词卡**
- 理由：カード 是全篇最核心的系统名词（フラグメント做卡、195 张卡面），`active.json` 却没有条目；skeleton/cards.zh 与 style.md 事实上已在用「卡片」，建议补登为定译，免得后续章节出现「卡／卡牌／记事卡」漂移。

### 4. 落書き → 涂鸦
- id 6525-6542（本批共 7 处）
- 建议：**涂鸦**
- 理由：skeleton/cards.zh 卡 1（「走进教室时，看到课桌上的涂鸦」）已用此译；该词是卡 1 的触发物，属于跨轨复现词，建议补登定译。

### 5. ★存疑（非术语）：6428「いちにーろく」数字串疑似不全
- id 6428：`彩野さんは頷くと、いちにーろく、と、小さく声に出して言う。`
- 现状：她复诵的是暗号串开头的『１９２６』，但原文假名只有「いち・にー・ろく」（缺「きゅう」）；紧接的 6430 却是完整的「１９、２６」。lua 原文已核对，确为 `いちにーろく`，非提取误差。
- 本批处理：按「原作故意的字面不一致保留不修复」原则**照译不补**——「一、二——六」（长音 ー 依车道惯例作「——」）。
- 请人工复核：若判定为原作笔误且中文读者会读成错字，可改「一、九、二——六」；此改动涉及暗号串族，需统一裁决。
