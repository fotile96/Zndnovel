## 一、两条通道独立撞上同一处，但给的解法相反：`14611`

```
JP   【＊＊＊】「うん。なんかすごい。私も最近入ったばっかりだから、初めて見たときはびっくりしちゃった」
现译 【＊＊＊】「嗯。总觉得好厉害。我也是最近才刚入学的，第一次看到的时候吓了一跳」
```

场景是サクラ的日记里，她与「＊＊＊」（后一行揭名为アヤノ）在**中庭**初遇。

| 通道 | 提案 | 理由 |
|---|---|---|
| fable-wf | 「我也是最近才**刚来这里**的」（备选：刚进来的） | 原文 `最近入ったばっかり` **没写入的是什么**。入学／入院两读并存正是机关（对应真相层的アヤノ入院），现译「刚入学」把它坐实到虚构侧。援引**全知纪律第 2 条**：原文有歧义处保持歧义 |
| opus46-wf | 「我也是最近才**刚住进来**的」 | §0 取义：场景是医院中庭，`入った` 应为入院；Ayano 因失眠住院才结识サクラ |

**我的读法：fable-wf 更稳。** 两个提案都在消歧，只是消向相反的一侧——
opus46-wf 把它坐实到真相侧，等于替读者提前揭穿这本日记的双层结构，
比现译的「入学」错得更远。「刚来这里」两侧都不站，才是原文的样子。
但这一处关系到本作最核心的叙事机关，请你自己看一眼再定。

## 二、`15147` 的提案被机械闸误杀了，队列里看不到

glm-5.3 提议把 `15147`「我轻轻笑了一声。」改成「我不由地轻声笑了。」，
理由是与五行之外的软锁锚点 `15142`（`私はクスリと笑う。`）同句——
日语只差时态（`笑う`／`笑った`），中文无时态差。

它被 ingest 的**「疑似错位」启发式**判死了：该启发式在「候选的 zh 与同批另一个
id 的 opus 逐字相同、而两者 jp 不同」时判定通道错行。这里的逐字相同是**有意的
族对齐**，不是错行——**这是一次误杀**。

⚠ **glm-5.2 独立提了同一条，同样被同一条启发式判死**。两条通道各自读出这个族
对齐需求、又各自被同一个闸拦掉——这就不是巧合，是该启发式缺一个正当出口。

⚠ 同时暴露一件事：**同一动词的时态变体不是同 jp，W4 与剥壳同句族都看不见它**。
`クスリと` 全库 7 处目前是两形并存：

| 形 | ids |
|---|---|
| 不由地轻声笑了 | 9407 · 10256 · 11348 · 15142 |
| 轻轻笑了一声／轻轻笑了笑 | 12931 · 14807 · **15147** |

（另：SEG-0/1 纪要里那条 `クスリと` 写得像给全族下了定义，实际只动过三行，
措辞已更正——它现在只锁死「不可用『噗嗤』」这一点。）

**要你定的是**：这两形要不要统一？若要，往哪边？`15147` 的提案（两条通道各一份）
都已经死了，无论你怎么定，我都得手工落 patch。fable-wf 与 ds-flash 在 `15147`
上是照抄。

## 三、`15062` 的请裁也丢了——通道把请裁文字写进了 `alts`

opus46-wf 在 `15062` 上把请裁问题写成了一个**字符串**放进 `alts` 字段
（契约要求 `alts` 是 ≤2 条的列表），整行被结构闸判死，提案和 note 一起没了。
闸拦得对——保税仓不能进畸形数据——但问题本身不该跟着丢，原文抄录如下：

```
JP   私だって……。気がついてないワケじゃない。
现译 我也……。并不是没有察觉。
提案 我又何尝……没有察觉。
```

> §11(b) 态度显化：「だって」起句带情感反驳，「我也……并不是没有察觉」→
> 「我又何尝……没有察觉」——「何尝」把反问的恳切加回来。
>
> 请裁：「何尝」是否太书面？原文是サクラ在心里为自己辩护——她明知一切却还是
> 教了咒语。「又何尝」还是「并不是」，哪个更贴这种自我挣扎？

同样：无论你怎么定，得手工落。
