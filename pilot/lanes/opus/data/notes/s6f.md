### 记录性判断（非提案）

- **锚点 10 条逐字沿用**：15290 / 15334 / 15336 / 15337 / 15377 / 15383 / 15388 / 15445 / 15463 / 15510。
  其中 **15445 的锚点 jp 只是本行的连续子串**（`『ためいき、…、おしまい』`），故译文＝锚点 zh 原样嵌入 +
  `という文字が書かれている。` 的译文（「上面写着『…』这几个字。」），引号内一字未动。
- **15465 沿用已入线 14108**（＝锚点 13763 的 `『……』` 引用形变体）：内层 `『』` 原文即已略去，中文同样只去内引号，
  与 anchors 的 recall 注记一致。
- **15390 `受験でも控えてたかい` ——已知双关损失。** 原文的 `落ちる` 一词串起「坠落／掉落／考试落榜」三义，
  15390 是第三义的落点（老板猜他怕"落榜"）。中文侧的「掉」由锚点 15383/15388/15389 锁定，而「掉」不含落榜义；
  改用「落」虽能接「落榜」，却要回改三条锚点，**不做**。本行按字面译「难道是快要考试了？」，双关链在此断一环。
- **15470 `５０音` → 「五十音」**（不随全角数字）。判据：style.md v7 的「数字形制跟随原文」限定于 UI／系统串、
  刻意字形游戏、暗号数字串，本行三者皆非；而同一概念的已入线两处（7597 `五十音`、13858 `50音順`）都作「五十音」，
  家族一致优先。行内 `『あいうえおかきくけこ……』` 作为**手迹实物**原样保留假名。
- **15391 `首を横にふった` / 15408 `首を横に振った`**：原文送假名写法不同，中文无载体，两行同作「我摇了摇头。」
  （15408 有已入线先例）。属不可复现的字面差异，非「修复」。
- **15320 `１００パーセント／１２０パーセント` → 「１００％／１２０％」**：全角数字原样保留，`パーセント` 取符号形；
  s7f 侧的同族 5347（`１２０パーセント`，未入线）建议同形。
- **15341 店长→≪マスター≫ 的改口保留**（voices/naoya.md §2 具名）：中文作「从店长……不，从≪老板≫」，`≪≫` 原样。
  说话人标签同段由【居酒屋店长】切到【老板】，按 speakers.json 分立不归并。
- **15417 `千秋さん`（由加里口中，儿童期）→ 「千秋」**：随已入线 9065／9072／9075／11038／11042 五处（5/5）；
  e1f 3911 的「千秋同学」属五年后场面，不同期，不冲突。
- **15396 `遅かったね、直哉君` → 「来晚了呢，直哉君」**：与锚点 6067「来晚了呀」／e1f 3904 镜像句对同词干，
  同一说话人同一措辞，未另起译法。
- **15405 千秋/彩野 的"放飞"引语**沿用 voices/chiaki.md 已登记的两条：
  『直哉回来得也太——慢——了』『又喝上啦——！』；彩野侧的 `ふざけんなー` 新译『别闹了——』。
- **15436 不补引号**：`ちょっとごめんなさいと言うと` 原文无 `『』`，中文用「说了声稍等一下」承接，按 v7 口径不补。
- **15427 / 15428 `『話し合い』` 保留原文引号跨度**，作『谈话』；15429『預かってくれていた』同样只译不移边界。
