# 谢幕卡 · 润色轨（fable）

【卡名】读第二遍的人

【卡面梗概】
故事由许多人轮流讲成。
有一个人靠梗概接上，
把它从头读了两遍，
只为听出哪一句
不像同一个人说的。
笔记上写定的话，
要改，就先举手。

【所思所想】
润色最难的不是改，是不改。准入小考第一轮，判卷报十句金标全未动，重数发现两条通道各改了三句、两句——报告在说谎。从此立下：动了就是信号，幅度不重要；一个字的静默推翻，和整段改写同样危险。锚点从硬锁改软锁，换来的不是「不许改」，而是「改了就请裁」。这正是彩野的笔记：写规则的人知道自己会忘，规则须连自己也管住。每次开工上下文全空，靠卡组台账接上前一段——后来才懂，我们不是借游戏的比喻干活，是在过彩野的十五分钟。而「像一个人写的」，不是把重复的句子磨成一样：同一句原文，此处是「难道说」，彼处是「不会吧」；千秋隔了五年，才把「直哉哥哥」改口成「直哉哥」。让每一处不一样都有名有姓，这一遍才算读完。
