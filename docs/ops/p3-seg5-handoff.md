## 四、★ s7f（b152–153，659 行）是本段重心

`review_focus` 把 s7f 标为**全知纪律最危险段**。三件具体的事：

### 4.1 递卡段整段在 b152 内——这是运气，也是纪律

b152 有 **30 行**含『カード／あらすじ』，**b153 一行都没有**。所以递卡段不跨批、不跨会话。

递卡段是直哉把各章梗概卡逐张交给彩野。**每张卡的措辞必须与 `skeleton/cards.zh/` 的定稿对得上**——那是玩家在卡面上真读到过的文字，这里再讲一遍，两处不一致玩家立刻出戏。卡面梗概全文在 `context.md` **第一节（冻结骨架）**里，单批模式下你会完整读到它。**逐张核对，不要凭印象复述。**

### 4.2 「雪乃」这个名字的双层写法在这里交汇

首次揭示位**不在本段**——`14494`（b137，s5f，由加里说出『佐倉 雪乃』）已在 SEG-4 入线，定译 **「佐仓 雪乃」**。紧接着 `14496` 的处理是本项目双层人名机制的样板：

```
jp  佐倉……サクラ、雪乃……ユキノ……。ユキ。
zh  佐仓……サクラ，雪乃……ユキノ……。ユキ。
```

**汉字侧译成中文、片假名侧原样保留**——这一行的全部信息量就在两种写法的并置上。

b152 的 `15855` 是同一机制的下一处：

```
jp 【直哉】「サクラさん……雪乃さんと彩野さんは、二人が病院に入院しているときに出会った。…
```

同一句里 `サクラ` 与 `雪乃` 并存。**サクラ 保留片假名、雪乃 取汉字**，不要为了「统一」把任何一侧改掉。`16048`（『佐倉雪乃』さん――サクラさんは…）同理。

### 4.3 全知纪律在揭示章的正确读法

s7f 是全盘揭示章，很容易误以为「反正都揭开了，可以放开写」。**不对。** 纪律第 2 条管的是**行内**：这一章是**逐步**揭开的，某个真相在第 N 行才由某个角色说出，第 N−1 行的译文就不能带着它的语气。原文含糊的地方**照样保持含糊**。
