# 术语提案 · s1f（opus 车道）

> 试点期术语表冻结，本文件只做提案登记，不做裁决。格式：批次 / id / 原文关键词 / 建议译法 / 理由。

## batch 29

### 1. 作業記憶 → 工作记忆（与已定「手続き記憶→程序性记忆」语义打架，需裁决）
- id 6714：`【彩野の母】「『例の』作業記憶……」`／id 6715：`作業記憶。身体が覚えている記憶。`
- 建议：**工作记忆**（`作業記憶`＝ワーキングメモリ的汉字写法，中文心理学标准译名）
- 现状：原文用的是 `作業記憶`，但紧跟着的注释「身体が覚えている記憶」恰恰是 v6 已定的 `手続き記憶→程序性记忆`（直哉在 6470 前后刚给彩野讲解过）。即**原作把两个术语混为一谈**——从人物看这很自然：彩野母亲是外行，半记着医生说过的词。
- 本批处理：按 style.md「原作故意的字面不一致保留不修复」照字面译作「工作记忆」，没有替原作改成「程序性记忆」。
- 请裁决：(a) 维持字面「工作记忆」（本批做法）；(b) 统一为「程序性记忆」，代价是抹掉母亲用词不准这一人物细节。若选 (b)，6714、6715 两条须一并回改。
- 附：与 s0f batch 2 §2「长期记忆／短期记忆」同属一个术语族，宜一次裁完。

### 2. お母さん（直哉当面的称呼）→ 『妈妈』（标签已由 speakers.json 锁死，正文口径请复核）
- id 6729–6734（命名桥段）；其后【お母さん】标签在本批共 48 条
- 现状：`glossary/speakers.json` 已定【お母さん】→【妈妈】。本批据此在 6734 处把说话人标签从【彩野的母亲】切换为【妈妈】——**这个标签切换本身就是原作的叙事装置**（直哉接受了这个称呼，叙述视角随之变亲近），中文完整保留。
- 冲突点：`glossary/voices/naoya.md §2` 给彩野母的当面称呼留了「阿姨」的备选。中文里 23 岁男性当面叫同学母亲「妈妈」，比日文 `お母さん` 重得多（近乎女婿口吻）。
- 本批处理：正文内一律用『妈妈』（6732/6733/6735）。因为 6735「さすが口に出すのはなかなか……気が引けた」与 6737 彩野起哄「干脆叫她名字」这两句的笑点，正建立在"这个称呼叫出口很难为情"上；换成「阿姨」笑点全塌，6735 整句失去理由。
- 请裁决：正文内维持『妈妈』，还是改「阿姨」而只让 speaker 标签保持【妈妈】（会造成标签与台词不一致，不推荐）。

### 3. 中庭（民宅）→ 庭院（与校内『中庭』同词不同物，建议立分支）
- id 6665：`中庭も広い家が多かった。`
- 现状：校内场景的 `中庭` 已事实固定为**中庭**（探索地图点名、卡 194「中庭的アヤノ同学」、卡 110「中庭的雪」等）。此处指的是住宅区民宅的院子。
- 本批处理：作**庭院**。建议立分支：校内→中庭；民宅→庭院。理由是中文「中庭」用于普通民居既不自然，又会与校内那个高频地点撞名，读者会误以为在写学校。

### 4. サクラちゃん → 小サクラ（沿用既有，仅登记）
- id 6846、6849、6860、6881
- 处理：按 style.md「～ちゃん → 小～（サクラちゃん→小サクラ 酌情）」与 skeleton 卡 93「小サクラ」，统一作**小サクラ**。
- 附注：6849 原文写作 `『サクラ』ちゃん`（引号只括名字本身），中文把引号整体外移作『小サクラ』——中文无法在词中间插引号而不破读。若委员会要求引号位置逐字对应，需另想办法。

### 5. 押し入れ→壁橱、付箋紙→便签、リビング→客厅、インターフォン→对讲机（居家名词小族，建议补登）

- 理由：彩野家场景在 s1f 之后的 s5f／s7f 还会反复出现；不定口径容易在「壁橱／储物间／橱柜」「便签／便利贴／标签纸」「对讲机／门铃／可视门铃」之间漂移。

### 6. メモ→字条 与 付箋紙→便签 在相邻两句指同一批纸（W2 相关，已知别扭）
- id 6899：`「キオク」に関しての注意書きの付箋紙が何枚か貼られていた`／id 6900：`メモの内容のいくつかは手帳に書かれていたものと同じものだった`
- 本批处理：6899 用「便签」（对 `付箋紙`），6900 按 active.json 用「字条」（对 `メモ`）——同一批纸在相邻两句换了称呼。原文本身也换词（付箋紙→メモ），故未强行统一。
- 关联：s0f batch 2 §1 已提案给 メモ 立语境分支；本条是该提案的第二个案例——此处的 メモ 既不是手帳，也不是ユウイチ口袋里那张关键道具『字条』，而是贴在书桌与床头的便签纸。三种物件共用一个日文词，建议裁决时一并覆盖。

### 7. オカルト→『灵异』、心霊特集→灵异特辑、怖いお話→恐怖故事、トリック→机关（建议补登）
- id 6774／6776（心霊特集・怖いお話）、6820（オカルト）、6826（トリック）
- 理由：这一族词是本作"先立怪谈、再拆穿机关"结构的元语言，在 s2s／s3s 的传闻线与 s6f 会再次出现。「机关」一词还需与已定的 ナゾトキ→谜题、オマジナイ→咒语 划清界限，避免三者互相顶替。

### 8. ★存疑（非术语）：6853 首句与后文自相矛盾，疑似原文脱字
- id 6853：`サクラさんは実在した。僕が知りうる限り、『現実の』僕たちの学校内、同級生や知り合いにもそういう名前の子はいなかった。`
- 现状：首句是断定句「サクラ 是真实存在过的」，可同句后半与 6854–6856 恰恰在论证"所以我一直以为她只是故事里的人物"，而 6858 给出的结论也只是「有存在过的**可能**」。语义上首句更像 `実在したのか。`（自问）。已核对 lua 原件（`lua_scripts/snr_s1_10_f.lua` 第 371 行），确为 `実在した。`，不是提取误差。
- 本批处理：按「不修复原作」照断定句译出——「サクラ同学是真实存在过的。」
- 请人工复核：若判定为原作脱字、且中文读者会读成逻辑错乱，可改为自问句（例：「サクラ同学，真的存在过吗。」）。此改动会改变该段的悬念节奏（断定句先抛结论、再回溯推理，也是一种写法），故不由译者自裁。
