> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 产出并冻结翻译骨架 skeleton-v1：197 张卡面梗概的日文转写与中文卡组、角色口调表、术语表 v1、伏笔锚点行——全部由 Claude Code 子代理完成，不调用外部 API。

**Tech Stack:** Claude Code 多模态子代理；PyYAML（仅用于校验脚本）。

## Global Constraints

- **禁止调用外部 LLM API**；全部翻译/转写由本 harness 的子代理完成。
- `png/`、`lua_scripts/` 只读。
- 转写必须逐字保真：保留全角字符、`……`、卡面换行以 `\n` 记录；不确定的字符用 `〓` 占位并在 note 说明。
- 翻译遵循 `glossary/glossary.v1.yaml`（Task 2 产出）；片假名/汉字双写法角色名必须使用 v1 裁决的两套中文写法。
- commit 规范：`type: 中文摘要`（本计划多为 `data:`）；main 直接提交。
- 标注 **CHECKPOINT（需用户）** 的步骤必须等用户裁决后才能继续。

- [ ] **Step 3: 写 tools/check_skeleton.py**

```python
"""骨架 YAML 机械校验。用法见 --help。"""
import argparse
import sys
from pathlib import Path

import yaml

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))
try:
    from tools.pipelib import display_width  # P1a 落地后共享同一实现
except ImportError:
    import unicodedata
    def display_width(s: str) -> int:
        return sum(2 if unicodedata.east_asian_width(c) in "FWA" else 1 for c in s)


def load(p):
    with open(p, encoding="utf-8") as f:
        return yaml.safe_load(f) or []


def main(argv=None):
    ap = argparse.ArgumentParser()
    ap.add_argument("--jp"); ap.add_argument("--zh"); ap.add_argument("--against")
    ap.add_argument("--range", required=True)
    args = ap.parse_args(argv)
    lo, hi = (int(x) for x in args.range.split("-"))
    want = set(range(lo, hi + 1))
    errs = []
    if args.jp:
        rows = load(args.jp)
        got = {r["card"] for r in rows if r.get("variant", "a") == "a"}
        if got != want:
            errs.append(f"jp 卡号缺漏: 缺{sorted(want-got)} 多{sorted(got-want)}")
        for r in rows:
            for k in ("card", "variant", "title_jp", "section_label", "body_jp", "note"):
                if k not in r:
                    errs.append(f"card {r.get('card')}: 缺字段 {k}")
            if not r.get("title_jp"):
                errs.append(f"card {r.get('card')}: title_jp 为空")
    if args.zh:
        zh, jp = load(args.zh), load(args.against)
        jpk = {(r["card"], r.get("variant", "a")) for r in jp
               if lo <= r["card"] <= hi}
        zhk = {(r["card"], r.get("variant", "a")) for r in zh}
        if zhk != jpk:
            errs.append(f"zh/jp 不对应: 缺{sorted(jpk-zhk)} 多{sorted(zhk-jpk)}")
        for r in zh:
            if not r.get("title_zh") or not r.get("body_zh"):
                errs.append(f"card {r['card']}: 译文字段为空")
            elif display_width(r["title_zh"]) > 28:
                errs.append(f"card {r['card']}: title_zh 超 14 汉字宽")
    print("\n".join(errs) if errs else "OK")
    return 1 if errs else 0


if __name__ == "__main__":
    raise SystemExit(main())
```

- [ ] **Step 2: 与 snr_common 的 plotTitle 表交叉验证标题**

```bash
uv run python - <<'EOF'
import yaml, re, unicodedata
titles = {}
for line in open("lua_scripts/snr_common.lua", encoding="utf-8"):
    m = re.match(r'plotTitle\[(\d+)\] = "(.*)"', line)
    if m: titles[int(m.group(1))] = m.group(2)
cards = {r["card"]: r for r in yaml.safe_load(open("skeleton/cards.jp.yaml", encoding="utf-8"))
         if r.get("variant","a") == "a"}
norm = lambda s: unicodedata.normalize("NFKC", s).replace(" ", "").replace("　", "")
bad = [n for n, t in titles.items()
       if n in cards and norm(cards[n]["title_jp"]) != norm(t)]
print("MISMATCH:", bad if bad else "无（card 0 无 plotTitle 属正常）")
EOF
```
