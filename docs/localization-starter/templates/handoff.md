# 会话交接

- 项目 / source revision / 工装版本：
- 唯一现行译文位置及 hash：
- 本段 / 路线 / 状态范围：
- 输入 manifest / 封卷回执：
- 已接受的 batch / decision ID：
- 未接受候选与原因（未裁决、陈旧底本、校验失败分别列）：
- 新裁决及适用范围；替代了哪条旧规则：
- 需召回的文本族 / 图片 / UI / 攻略 / 测试：
- 未知演出或插件效果；最小补证任务：
- 已运行验证（命令、版本、证据路径、分母、结果）：
- 未运行验证及理由：
- 下一步可直接执行的命令或任务：
- 当前工作区中他人的改动：

恢复先核对持久产物和 hash，再决定重跑范围。不依赖上一会话自述的完成状态，不重新采纳已过期候选。
