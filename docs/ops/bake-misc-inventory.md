## `event/`（121 张）→ 只有 `op_*` 6 张含字

115 张 `eve_*` 是 CG 收藏图，无烤字。**目录闭合。**

`op_1_a/b`、`op_2_a/b`、`op_3_a/b`，各 480×272 带透明，由
`snr_s0_10_f.lua:14-43` 在**序章一开场**依次加载，压在 `bg/bg_8_c_1` 上。

**演出形态**（读 lua 得来）：`_a` 淡入 → `keyWait(480)` → `_b` 淡入同时 `_a` 淡出
→ `_b` 淡出。三段各等一次按键。

### ⚠ `_b` 不是独立内容，是 `_a` 的**虚化版**

实测：高斯模糊 **r=1.5** 即可从 `_a` 重建 `_b`，alpha 平均残差仅 **0.4–0.5**
（满量程 255）；墨迹 IoU 0.89–0.91，高频能量 6.6–6.8 → 3.0–3.8（约减半）。

**所以只需翻译 3 段**，虚化版渲完再滤一次即可，不必也不该单独译。

### 三段原文（逐张读图转写，合成到真实底图后放大 2 倍）

1. `op_1`：あの人が私のもとから立ち去って、何年経っただろうか。／もし、今あの人と
   再会したら私は『どうなる』だろう、と考える事がある。／当時私があの人に対して
   抱いていた熱情を再び覚えることになるのだろうか、と。
2. `op_2`：でもすぐに私は首を横に振る。それは成し遂げられない『もし』である、と。／
   私が恋い慕った相手は『あの時あの場所にいたあの人』に対してであって、仮に今ここで
   あの人に再会したとしても、それは『今』この時この場所で出会う相手なのだから。
3. `op_3`：もし、私があの時のままの姿でいて、相手も同じように当時と何も変わって
   いないのなら、私は再び強く、深く、恋い焦がれることだろう。／それは間違いない。
   けれど、その『もし』は無意味だ。「時の流れ」は止める事も遡る事も出来ないのだから。

**这是叙事文本，不是 UI 文本**——第一人称「私」的题词式独白，主题「時の流れ」与
「再会」，与全作核心（直哉时隔多年回来见彩野）直接呼应。翻译时该按正文轨的口吻
与风格处理，不是按标签处理。
