# 登场角色 MBTI 人格侧写

- 分析：2026-09-22；落盘：2026-09-24。
- 性质：趣味向文本研究，不是翻译规范。角色口调、称呼的定译依据仍是 `glossary/voices/` 与 `glossary/style.md`，与本文冲突时以它们为准。
- 缘起：用户问能否重读原文与译文，给全部主要登场角色做 MBTI 侧写，故事层与现实层差别大的角色分开说。
- 底本：`work/out/read.md`（`tools/export_read.py` 于 2026-09-22 导出，车道 pilot/lanes/opus，HEAD a613273，16749 行译文）＋`analysis/text_digest/` 日文摘要。read.md 的行号随每次导出变动，本文引用一律以场景标题或 `scene_` 名为锚。
- 编外谢幕章（`layers/scripts/snr_finale.lua`）是本地化新增，不计入原作人格证据。

## 怎么做的

1. 主笔亲读序章 s0f、EX1（e1s/e1f）、EX2（e2s/e2f）的中文定稿，外加七份口调表与卡面梗概总表 `skeleton/cards.zh.yaml`。
2. 其余篇幅切成 8 段，每段一个子代理逐行读译文、对照日文 digest 采证：按 E/I、S/N、T/F、J/P 分列正反证据，标出入戏、附身、醉酒、GAMEOVER、失忆演出、扭曲投影等会让人格失真的状态。八份报告原文存在 [`evidence/`](evidence/)。
3. 主笔做跨段裁定。两句口头禅的归属用 grep 单独核过：「緻密な計算」在 `snr_s1_10_s.txt:384`（故事层）与 `snr_e1_10_s.txt:71`（真人）各出现一次；「お前とはいつも一緒にいる“けどな”」只出现在 `snr_s7_10_f.txt:586` 直哉的回忆里。
4. 落盘前把总论引句的出处又核了一遍，修正了对话版里的几处归属错误，见文末「勘误」。

**最大的前提**：故事层人物是彩野（部分出自雪乃）写出来的，他们的"类型"同时反映角色本身和作者的自我投射；现实层的彩野又被十五分钟记忆、创伤和「装乖」三重滤镜遮着。所以每个类型都带信心等级，备选类型是证据真的分叉，不是凑数。

## 逐人侧写

### 直哉（现实层）：INFJ，信心中高，备选 INFP

- **Ni 是主轴。** 他把一切收束成单一愿景：卡 0/卡 2 里从「她着急找笔」跳到「故事是她把世界与自己维系在一起的手段」，进而「把故事铭刻下来吧」；s7f 把散点收成「天台。那就是钥匙」，再推出「僕はこれからユウイチになる」的重演计划。EX2 里对药物副作用「建立起假说」也是同一路数。
- **Fe 是外壳，也是他的病。** 序章「我说谎了。在最要紧的事上」，全书复现句「我做出微笑。或者说，努力牵动脸上的肌肉，让自己能露出微笑」（僕は微笑む。あるいは微笑むことができるように顔の筋肉を動かそうと努力する）。s2f 他自己拆穿这层壳：「那绝不是温柔。我只是害怕，一旦伤害了谁，自己就成了坏人。不过是自保罢了」（単なる自己の保身だ）。由加里在 s3fb 的旁证更狠：「直哉君って、結構思っていることが表に出やすいのよね」，他撒谎其实很差。
- **Ti 用来建规则。** 名片背面写梗概的系统、「凡是语气有变化的词都记下来」、向彩野解释海马体与情景记忆时坚持「不加『约』字的、准确的时间」。e1s 里ユウイチ的评价吻合：「对这种怎样都无所谓的东西，反倒有股莫名的钻研劲儿」。
- **劣势 Se 在压力下爆发。** EX2 的自白是全书最关键的人格证据：二月在最糟的时机告白，「結局は自己満足だったんだろう」，然后「一人は死に、一人は取り残され、僕は逃げ出した」，五年后回乡是「期待着回忆已经失去」。平时他靠感官仪式稳住自己：行动前深呼吸、老地方的自动售货机咖啡、s4fa 里把头沉进浴缸想事情的老习惯（僕は昔から、何かに考え込むと、こんな風にして頭を湯船の中に沈め……）。
- **内向与沉默是一以贯之的自我定位。** s1f「真实是不说出口的东西。我就是这种角色啦」（僕はそういうキャラなの）；EX2 他引用ユウイチ对自己的评语：「『僕の一番悪いところは、一番大事な事を黙ってること』なんだ。アイツも僕の事をそういう風に言ってた」（真ユウイチ在卡 29 的回忆里当面说过同一句）。e2s 酒吧老板对千秋说起他：「基本、店にいても無口な子だったからね」。他还承认自己也在看医生、也在服药。
- **为什么不是 INFP。** 他的价值判断确实很私密（「不是我的作风」「我并没有那样的『资格』」），但做决定的标尺始终是别人的感受：对千秋坚持「僕らは対等であるべきなんだ」（s4fa），对她说「谁都没有错」（s7f），对由加里说「什么根本的错误，那种东西哪里都不存在」（s6f），最后把结局的所有权让给彩野（s4fb「End Roll 的所有权，属于她」）与千秋（s8f 交出笔记本）。这是 Fe 在裁决，Fi 只在自审时出场。
- **十七岁的他**只在雪乃日记里以「ユウイチ同学」出现：先问「含糖之类的，不要紧吗？」再送甜甜圈；被叫错名字时「诶？ 嗯、嘛，嗯……是啊」（え？ ええ、まあ、うん……そうだね）地默认了。同一副 Fe，只是还没学会说谎。

### 彩野（现实层）：INFJ，信心中，备选 INFP

- **E/I 是最靠不住的一轴。** 在直哉面前她省略号极多、先道歉先道谢；但由加里说她和千秋「二人ともお猫被りが大変お上手みたいね」（s6f），说她「尖っていた部分が、丸くなったような感じ」（s3fb）。母亲说她事故后「怒りっぽかったのが丸くなった」（s2f），由加里转述伤后头一两年「特别厉害」（s5f），母亲还提到她曾想把房间里的东西全部扔掉（s1f）。s1f 一进家门就是「我回来啦！」、推着直哉进门、邀他参观房间，直哉也注意到「像是绷紧的什么东西，松了下来」。教室里那个温顺的她，是表演加病理，不是基线。
- **Ni 式的无根据笃定。** 卡 175 宣布「这就是，故事。故事的，全部」，旁白补一句「那里既没有『可是』，也没有『因为』」；s4fb 自陈「根拠なんてない。理由なんて説明できないの」；卡 90 说 3B 才是「本来のお話の流れ」。她不解释，只知道。
- **Fe 与 Fi 各有铁证。** Fe：为直哉写下「直哉君在也不用吃惊哦」的备忘、替他的失言开脱「不用道歉，因为我的记忆会消失」（卡 89）、斥他对由加里失礼（卡 23）。Fi：「……いいの。私がつくりたいんだから」（卡 38），以及把「不让直哉背负那个角色」写成规则、生成 3B/4B 这种全员不得善终的分支——不给理由的价值决断。判 Fe 略重，因为她连自己的痛苦都拿来照顾别人。
- **强迫观念是游戏给的标签，不是这里的发挥。** 关键词卡 105『自我暗示』、106『强迫观念』写的就是她；EX2 直哉说她「无论如何都必须让那个未完成的故事『完结』」。Ni 的单点固着与劣势 Se 的冲动，在坠楼当天合体。
- **作者的自觉。** 卡 150「もしかしたら、私、『思い出してる』つもりで『つくってる』のかもしれない」；卡 14 直接问「我，性格真的是这个样子的吗？」。她清楚アヤノ不是自己。
- **十七岁的她**只能靠旁证：e1s 里ユウイチ说她「有点不爱出门的倾向」「总觉得，她是不是在什么地方硬撑着」，由加里记得「那么文静的Ayano同学」，小学时她离家出走躲进学校天台过夜。安静、写故事、硬撑、偶尔爆发。两种备选都说得通，INFJ 胜在「笃定」与「装乖」两条。

### アヤノ（故事层）：ENFP，信心中，备选 ESFP

- **外向被作者刻意调高。** 卡 9 彩野自己说故事里的人物「更接近，理想的样子吗？」，卡 14 直哉附和「写得稍微夸张一点，人物才更好动起来」。所以「絶対に負けないんだからっ！」、拍头、飞机撞人、「このタイクツでヘイワな学校生活、みーんな刺激が欲しいよねっ！？」都要打折读。
- **Ne 与 Fi 是没被改动的核。** s3s「このまま手に翼が生えて、窓から飛び立てたらどんなに気持ちよいものか」；s2s 把去处列一堆定不下来，「不行啊，脑袋的模式变得怪怪的了。得切换一下才行！」；对咒语先冲口而出再道歉，四个分支一律如此。
- **面具滑落处最像作者。** 目击亲吻后不是质问而是躲、逃、独处，关键词只有「先生、先生なんて――」，事后发现手心的指甲印、橡皮被拧断两截，「……这个，是我干的吗」。サクラ在信里点她「……アヤノさんはいつも逃げますよね」（s6s），天台上的扭曲投影也骂「『アヤノは、いつも逃げてばかり』」（s3s）。s3 这一段被采证员判成 INFP，正是彩野本人透了出来。
- **各章不一致本身就是证据。** s1 像 ESFP 的闹剧少女，s3 是 INFP，s4 从ユウイチ眼里看是守约的 ESFJ。一个外向程度随作者心情变化的人物，ENFP 是最稳的公约数。

### ユウイチ（故事层）：ESTP，信心中，备选 ISTP

- **Ti 与 Se 稳定。** 「いや、これも緻密な計算の結果と呼んで欲しいね」（s1s）；「铃声什么时候响，我连秒都掌握了。这里的钟慢４２秒」（s2s）；「結果見ようよ、結果」（s3s）；「とりあえず、動こう。動いてから考えてみよう」（s4s）。对钱仙的态度是价值宣言而不是论证：「そんなこと俺は誰かの指図なんて受けたくないね」「因为我就是看不惯」。
- **E 面是彩野加的。** 卡 9 她亲口说「那家伙可没有开朗到这个地步」；故事里他自己也承认「除了你，我跟别的女生基本都不怎么说话」，アヤノ说他「そもそも集団行動が向いてないんだって」。
- **第 4 章的他是叠加态。** ユウイチ视点里那套编号排查、把字条对着光照的推理，与直哉在 s4fa 推通话记录、s4fb 把威士忌举到日光灯下的动作同型。直哉在 s3fa 自己也察觉「对Yuichi这个人物的存在，迟迟拿不定主意似的」。

### ユウイチ（现实层）：ISTP，信心中低，备选 INTJ

- **材料只有三处**：e1s 由加里的回忆、s7f 直哉的转述、e2s/s6f 旁人证言。故事层的口头禅在真人口中重现：「緻密な計算と呼んでほしいね、先生」（e1s），说明彩野把真人的口癖写进了角色。
- **Ti 主导的制度玩家。** 「把考试分数和出勤天数都维持在过得去的水平，站在……中间位置」，老师们却当他是认真学生；对学校制度「明白归明白，可是就是会难受」，于是「反过来，也可以利用那套制度」。
- **Se 与独处并存。** 天台午睡、脱衬衫垫着看星星、泳池「相当拿手」、恶作剧「老师，你脚边掉了根烟哦」；同时「３０个人默默地坐上一个小时，这实在是有点吃不消」。酒吧老板说他一个人来店里时「話しかけにくい雰囲気があったな」。
- **Ni 的预感与劣势 Fe 的直球。** 感到アヤノ「像是把石头扔进一口特别特别深的井里」；最后一晚飞镖连赢、寄存威士忌、反复叮嘱「『もう落ちるのだけはゴメンだ』」（s6f 老板转述）；感情只会用最硬的方式说：「不想让给任何人。要是不趁现在在这里告诉老师，说不定一切都会一直这样下去」（e1s）。对彩野的口头禅『お前とはいつも一緒にいる“けどな”』只在直哉的回忆里出现，属于真人而非角色。
- **为什么留 INTJ 做备选。** 「因为，我藏着没说嘛」、e1s 结尾承认留学是「说实话，我是想逃走」的半真半假，以及 e2f 直哉推测他会为揭露医院黑幕「不管自己身上会发生什么」的硬度，都有 Ni-Fi 的长程色彩。但他的思维是拆解式而不是目标式，「……みんな嘘つきなんだ」（e1s）的失望更像劣势 Fe 的理想主义，所以取 ISTP。

### サクラ（故事层）与雪乃（现实层）

- **故事层サクラ：INFJ，信心中，备选 ENFJ。** 「オマジナイは人の心を反映させるもの」，教咒语「薬で言えば調合って感じ」，用谜题探アヤノ的「深层心理」，失望只留一声「轻到不侧耳细听就察觉不到」的叹息（s2s）。s6s 写到她当导演、事先叫好出租车、安排アヤノ留在天台，采证员判 ENFJ，因为这是彩野在追忆里把她写活了。天台上冷冷的「约定不守可不行」是彩野的扭曲投影，不算她。
- **现实层雪乃：INFJ，信心中高，备选 INFP。** 日记从 9/16 起写的是现实（9/13 与 7 月篇是她虚构的"上学的自己"），现实里她十三岁。自述「不擅长与人来往」，对传闻做逐层假说后自我消解「私の勝手な妄想なんですけれどね」；对病「生まれた時からこんな感じだったので」；发作时怕添麻烦，把伸向呼叫铃的手缩回被子；卡 185 把病情恶化解释成「悪いことをするから、だから、その罰が当たったんだと思います」。J 的强度在于那份死后执行的指示清单：日期、雨天备用日、触发条件、情感诱饵，一样不缺。
- **e2f 的 if 线是她没活成的自己。** 「オマジナイの全てに効果があったのなら、私は入院なんてしているはずもない」「たぶん。収集家のような感じ、だったと思う」——一个不信咒语却收集咒语的观察者；同时在直哉面前逞强，在脑子里预演见面时该说什么，追着要「不要忘记。我们还要再来哦」。健康版的她被写得更外向，与彩野改写アヤノ是同一手法。
- **她和直哉是同型，不是巧合。** 两人都替别人写好结局，再借人之手执行：她借千秋的信与录音，他借由加里与千秋的重演。全书两次"以爱之名的导演"出自同一种认知结构。

### 由加里／ユカリ（两层同体）：ENFJ，信心中，备选 ESFJ

- **两层其实连续。** 故事层课堂上「はいはい、みんな、休み時間終わってるよー」的热血翘班老师，是学生眼里的漫画版；s1 章末那个用诱导实验拆穿钱仙、断言「自己亲口说出来的话，印象更深」的理性教师，则是彩野替卡片系统写的注脚。现实层的她把两面都收了。
- **Fe 主导，边界会失守。** e1s「我本来是想更认真地面对每一个学生的」「我到底有没有教别人东西的资格呢……我没有自信」；对ユウイチ「我阻止不了。我不想阻止」；s3fb 坦白「私の方から、ユウイチ君に口づけしたの」。现实层她一上午动用门路查千秋家况，彩野母住院后提出搬去同住，把「死なないで。教え子が死ぬところ、もう見たくないの」（s6f）当成放行直哉的唯一条件。
- **Ni 与 Se 都在。** 假说式思维「如果这是彩野同学『为了活下去所必需的记忆』，那说不定就会有什么变化」（s3fb）；同时能喝空好几瓶脸不变色、临时起意「呐，我们去游泳池吧」（e1s）、酒后拽着人走。劣势 Ti 表现为对措辞的执拗自纠：「『たぶん』じゃないね。『本当に』、目撃されてたみたいね」（s3fa）。
- **五年的沉默是恐惧，不是冷。** 「怖かった。でも、それが全ての間違いの元だった」（s6f），随身带着ユウイチ字条的复印件，一直等到直哉来问。s7f 那句「これは賭けなのよ。保証はどこにもない」是她把自己的赌局交了出去。

### 千秋（现实层）：INTJ，信心中低，儿童期看起来像 ISTJ

- **儿童期的证据全是 Si 与 Te 式的。** s1f「６年前。病気でした。死にました。今はいません」，直哉评「简单，而且，是封闭的」；「我，不是Sakura。……我的名字，是『千秋』」；s3fa「覚えるのは得意です。私」；s4fa 趁直哉泡澡删掉自家电话的通话记录，事后主动坦白。守了姐姐的嘱托整整五年，指令里连雨天备案都照做。
- **长大后长出了 Ni。** s8f「我怎么也没法觉得，故事里登场的人物『只有』Yuichi学长」，一个不协调点想了好几年。同一场戏在两处结尾的版本不同：s8f 里她说「私、ハッピーエンドなんて書けないかもしれない」；EX2 结尾（e2f）则是「結末だけは、先に決めてるんです」「物語の最後は、ハッピーエンドにしたいんです」。EX2 里她用名册、厚生省网站、一个个电话把药害与封口线拼出来，老教师叫她「万事通博士」——自己查完之后，她先定了结局。
- **Fi 藏在敬体后面。** s2f「みんな子供だから」；s6f「お父さんも、お姉ちゃんも、お母さんも、みんな、私の前から消えてしまいました」；s8f 平静地问「直哉さんは、人を殺したくなったときって、ありますか？」，被回避后说「……老师，真温柔呢」。s7f 那句「ほんとうに、そう思いますか？」说明她对"温柔的姐姐"并非单纯崇拜。
- **为什么不干脆判 ISFJ。** 由加里说她和彩野都「お猫被りが大変お上手」，私下会冒出「なおや帰ってくるのおせー」；她的沉默是丧亲后的自保，不是 Si-Fe 的天性。真正稳定的是：先定结局，再收集事实，情绪不外露。

### 配角速写

- **彩野母，ESFJ，信心中。** 「妈妈她呀，是那种一认准了就马上钻进去的类型」（s1f 彩野语）；家里不看艺人节目、把「当时」的东西藏起来、遗物戒指改成项链免得记忆断裂时慌乱；过劳倒下还说「没什么好担心的」。直哉的总结是母女一样「不想让对方多操心」。
- **小菊／筑紫，ESFJ，信心低。** 故事里她桌面整齐、转笔、替老师和学生两边都想（「アヤノの気持ちもわかるし、先生の気持ちもわかる」）；e2s 里真人筑紫说「其实呢，我一直都后悔着。当时，要是跟那个人说句话就好了」，也看出「他呀，大概，一直都望着她那边」。
- **酒吧老板，ISFJ，信心低。** 守了五年的寄存，记得直哉少年时只喝牛奶，最后对千秋说「你的故事，写完了让我读读好吗？」。
- **护士，ISFJ，信心低。** 「我心里，觉得那简直跟傻瓜似的。那种事早晚都会露馅的嘛」，两次拒答后仍把知道的全说了；e2f 里替雪乃把关「他呀，你可要好好珍惜才行哦」。
- **现任教师，ESFP，信心低。** 拟声词多、爱捧哏、跟电脑搏斗，末了「朝着什么目标往前进的孩子，总归是好的嘛」。s0f 的【教師】（OYA 语音）与 e2s 的【≦教師≧】语气同型，疑为同一人。
- 雪乃与千秋的生父（e2s）只够定性为施虐者，不做类型。

## 跨层观察

- **每个被写进故事的人都被"调亮了一档"。** 彩野把自己写成 ENFP，把ユウイチ写成 ESTP，雪乃在 if 线里把自己写得像 ENFJ。
- **被写的两位真人偏 P，动笔编结局的三个人全是 J 型**：直哉、雪乃、后来的千秋。这大概比任何一张类型表都更像这部作品的底色。
- **直哉与雪乃同型**，见雪乃一节末条。

## 保留

- 故事层三人的类型都是"作者眼中的他们"。
- 彩野的类型被十五分钟记忆、事故后情绪期和「装乖」压变形。
- 千秋从十岁到十五岁跨度太大，单一类型本来就勉强。
- 信心等级反映各段采证员结论的一致程度，不是统计意义上的可靠度。
- 证据卷未经人工逐条复核；总论引句已在落盘前复核出处。

## 勘误（对话版 → 本文）

落盘前复核发现对话里给出的版本有以下问题，本文已改：

1. 酒吧老板说的「無口な子」指的是直哉（上下文是「彼が教えてくれたのかい？ 君に？」），不是ユウイチ；形容ユウイチ的是「話しかけにくい雰囲気」。
2. 「結末だけは、先に決めてるんです」「ハッピーエンドにしたいんです」出自 EX2 结尾，s8f 同场的千秋说的反而是「ハッピーエンドなんて書けないかもしれない」。
3. 「尖っていた部分が、丸くなった」是由加里在 s3fb 说的；母亲在 s2f 的原话是「怒りっぽかったのが丸くなった」。
4. 删去两条弱证据：护士说的「像在合谋什么恶作剧的姐妹一样」指的不是千秋；「俺は、アヤノの事が、好きだ」是 s7f 直哉扮演ユウイチ时的台词，不能当真ユウイチ的证据。
5. 「谁都没有错」是 s7f 对千秋说的；对由加里说的是「什么根本的错误，那种东西哪里都不存在」（s6f）。
6. 「集団行動が向いてない」是故事层アヤノ说故事层ユウイチ，已从现实层ユウイチ的证据里移到故事层。
