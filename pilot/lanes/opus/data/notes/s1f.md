## batch 29

### 1. 作業記憶 → 工作记忆（与已定「手続き記憶→程序性记忆」语义打架，需裁决）
- id 6714：`【彩野の母】「『例の』作業記憶……」`／id 6715：`作業記憶。身体が覚えている記憶。`
- 建议：**工作记忆**（`作業記憶`＝ワーキングメモリ的汉字写法，中文心理学标准译名）
- 现状：原文用的是 `作業記憶`，但紧跟着的注释「身体が覚えている記憶」恰恰是 v6 已定的 `手続き記憶→程序性记忆`（直哉在 6470 前后刚给彩野讲解过）。即**原作把两个术语混为一谈**——从人物看这很自然：彩野母亲是外行，半记着医生说过的词。
- 本批处理：按 style.md「原作故意的字面不一致保留不修复」照字面译作「工作记忆」，没有替原作改成「程序性记忆」。
- 请裁决：(a) 维持字面「工作记忆」（本批做法）；(b) 统一为「程序性记忆」，代价是抹掉母亲用词不准这一人物细节。若选 (b)，6714、6715 两条须一并回改。
- 附：与 s0f batch 2 §2「长期记忆／短期记忆」同属一个术语族，宜一次裁完。

### 2. お母さん（直哉当面的称呼）→ 『妈妈』（标签已由 speakers.json 锁死，正文口径请复核）
- id 6729–6734（命名桥段）；其后【お母さん】标签在本批共 48 条
- 现状：`glossary/speakers.json` 已定【お母さん】→【妈妈】。本批据此在 6734 处把说话人标签从【彩野的母亲】切换为【妈妈】——**这个标签切换本身就是原作的叙事装置**（直哉接受了这个称呼，叙述视角随之变亲近），中文完整保留。
- 冲突点：`glossary/voices/naoya.md §2` 给彩野母的当面称呼留了「阿姨」的备选。中文里 23 岁男性当面叫同学母亲「妈妈」，比日文 `お母さん` 重得多（近乎女婿口吻）。

- 请裁决：正文内维持『妈妈』，还是改「阿姨」而只让 speaker 标签保持【妈妈】（会造成标签与台词不一致，不推荐）。

### 3. 中庭（民宅）→ 庭院（与校内『中庭』同词不同物，建议立分支）
- id 6665：`中庭も広い家が多かった。`
- 现状：校内场景的 `中庭` 已事实固定为**中庭**（探索地图点名、卡 194「中庭的アヤノ同学」、卡 110「中庭的雪」等）。此处指的是住宅区民宅的院子。

### 8. ★存疑（非术语）：6853 首句与后文自相矛盾，疑似原文脱字
- id 6853：`サクラさんは実在した。僕が知りうる限り、『現実の』僕たちの学校内、同級生や知り合いにもそういう名前の子はいなかった。`
- 现状：首句是断定句「サクラ 是真实存在过的」，可同句后半与 6854–6856 恰恰在论证"所以我一直以为她只是故事里的人物"，而 6858 给出的结论也只是「有存在过的**可能**」。语义上首句更像 `実在したのか。`（自问）。已核对 lua 原件（`lua_scripts/snr_s1_10_f.lua` 第 371 行），确为 `実在した。`，不是提取误差。
- 本批处理：按「不修复原作」照断定句译出——「サクラ同学是真实存在过的。」
- 请人工复核：若判定为原作脱字、且中文读者会读成逻辑错乱，可改为自问句（例：「サクラ同学，真的存在过吗。」）。此改动会改变该段的悬念节奏（断定句先抛结论、再回溯推理，也是一种写法），故不由译者自裁。

## batch 31（id 17006–17011，s1f 章尾『游戏内小说』通知 6 条）

本批 6 条全是系统说明文（【■おしらせ】），虽登记在 s1f 章内，语域却与本章正文完全不同：是面向玩家的说明书口吻，接在已译的 17004/17005 之后成组。以下 4 条提案。

### 8. ゲーム本編 / 本編 → 正篇（新词；全作仅本批 3 处，此译即先例）
- id 17007（`ゲーム本編とは独立した…`）、17009（`本編の進行により…`）、17010（`ゲーム内小説とゲーム本編の関係`）
- 现状：`active.json` 无条目；`data/ledger.jsonl` 全库检索 `本編` 只有这 3 条，全部落在本批，**此后再无第二处**。
- 本批处理：**正篇**（`ゲーム本編`→游戏正篇，单用 `本編`→正篇）。
- 理由：中文「本篇」在 ACG 圈虽通行，但字面易被读成"本章/这一篇"；「正篇」与「游戏内小说（外传性读物）」的对立关系一眼可辨。
- 附带区分：17010 后半的 `ゲーム自体` 另作**游戏本身**，与 `本編`＝正篇 分开——原文这一句里两词并存，是刻意的层次差。
- 请裁决：立条目 `ゲーム本編→游戏正篇`，或改判「游戏本篇」。因只此一批，改判成本极低。

### 9. 参照 → 浏览 / 閲覧 → 阅览（沿用既有先例，请补登为固定二分）
- 参照：id 17008（`ご参照いただけます`）、17009（`参照できる数`）→ **浏览**；先例 6631「浏览故事的后续」、7307「可以从Ｆｒａｇｍｅｎｔ模式中浏览」（均已入 forward）。
- 閲覧：id 17006（`閲覧するスタイル`）、17007（`小説閲覧用のモード`）→ **阅览**；先例 17005「阅览方法」、17061「可以从这个ｌｉｂｒａｒｙ中阅览」（均已入 forward）。
- 说明：原文在同一组通知里交替使用两词（17005 用閲覧、17009 用参照），中文若合并成一个词并不影响理解，但既有译文已把二分做出来了，本批照办。
- 请登记为固定条目，避免后续批次（16818 等仍未译的同型通知）漂移。

### 10. モチーフ → 题材（与 id 2033 的「原型」分歧，按语境分译）
- id 17008：`脳をモチーフとした作品` → **以脑为题材的作品**
- 分歧点：已译 id 2033（`似たような子がモチーフとなった`）作「以某个相似的孩子为**原型**」。
- 判断：`モチーフ` 指人物来源时＝原型，指作品主题时＝题材/主题；中文没有一个词能兼任。本批取「题材」。
- 请裁决：是否立"按语境二分"的条目（`モチーフ`→原型／题材），还是统一某一译法。另有未译的 id 16208（`彩野の幼少期の記憶をモチーフにしている`）将来会撞上同一问题，那处按语义更接近「原型/取材」。

### 11. 縦持ち → 竖持主机（设备名在原文中缺省，中文补出）
- id 17006：`方向キーを下にした縦持ちで閲覧する` → **方向键朝下、竖持主机的方式阅览**
- 说明：原文只说「縦持ち」（竖着拿），未点出拿的是什么；中文单说"竖持"不成句，故补「主机」。
- 备选：**掌机**（PSP 更准确）／**机体**。选「主机」是因为它是家用机/掌机通用的说明书标准词，且本作其他 UI 文本无同类先例可对齐。
