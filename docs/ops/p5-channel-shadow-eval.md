## 二、★ 同模型不同派发形态：30 改动 vs 0 改动

opus 4.6 + max + 同一 prompt，Workflow 形态改 30 处、paseo 形态**逐字照抄 569 行**（153 条 note
全是肯定现译的评语，score 84–92）。

paseo 侧不是偷懒：日志显示它读全了 92 万字节、写了 /tmp 辅助脚本、逐条援引 P5 守门条款论证
「未达『确实错/确实生硬』门槛」。**它把守门三条读成了「不确定就别动」的极限**，正是
CLAUDE.md 警告的「形式完美、实质为空」。而 wf 形态同模型改的 30 处里，`错开视线→移开视线`、
`乱了方寸→失态`（§6 禁旁白成语）明显成立——「0 改动」是欠改而非正确读法。

**推论（prompt 设计风险）**：守门三条前置 + 多条「P5 不得再提」禁令，可能压过成品线三则。
契约需要配平条款（建议：零改动/极低改动率交卷须在批末逐条说明检视过哪些面，且该说明进
channel_feedback）。这条对全部通道有效，不只 opus46。

## 三、四条活跃通道的实质质量

**互补性强、重合极低**：两两重合仅 2–5 个 id（各自改动 14–30）。加通道确实扩覆盖面，
不是同一批发现的重复投票。

**共识信号**：`6118`（蝉鸣句）被**全部四条活跃通道**独立标出——而它恰是我在 v19 引入的
孪生劈叉（已在 `a579eb2` 修正）。四通道一致命中同一行，是真缺陷的强信号。

**glm-5.3（20 改）**：
- ★ `6200` 抓出真取义偏差：`彼女のためにもなる` 是获益义（对她也是好事），原译读成目的义
  （「也是为了她」）——附 alts、显式请裁，§0 纪律标准动作。
- `6204`「啪地跟值日的孩子说一声」→「好好地」：`ビシッと` 非拟声——**与 reader 报告 chunk-01
  B1 的独立发现完全一致**（该条当时未落地）。
- `6220`/`6282` 正确套用 §5(d) 判据 2 并标「段级」；`6508` 抓「空无一人…空空荡荡」三「空」撞车（§15）。
- `6612`/`6626` 读点移位按 §7(b)，且明写「三连复沓原样保留」——保护面同时守住。

**glm-5.2（14 改）**：
- ★ `6374`+`6375` **回声对同改**（直哉用词→彩野复述），批注明写 §18 族内同改——P4 全程最难守的纪律。
- ★ `6186` 发现译者补的弯引号 “” 与全篇 「」 体例不一，**不自行统一而是显式请裁**，并说明
  「弯引号逐字锁定条款管的是原文自带形制，管不到补引号位」——判据边界辨得清楚。
- `6118` 附 alts，两案差异说明具体（保「闹脾气」词面 vs 换搭配）。
- 改动更保守但零噪声，score 区间（改动 70–78 / 照抄 92+）分离清晰。

**opus46-wf（30 改）**：批注引用条款号最精确，`6186「做作」→「讨人嫌」`（嫌らしい 是「让对方
不快」不是「自我表演」）是四通道里最深的一处取义修正。**但引入一处真缺陷**：`6542` 删掉了 jp
里确实存在的 『落書き』 引号，批注却称「此处不是引用」——事实错误，且 『』 不在硬闸 MARKS 内，
机械闸抓不到。

## 五、结论与建议

| 通道 | 结论 |
|---|---|
| **glm-5.3** | **建议进正式矩阵**：改动量与质量均达标，§0 抓取力强（6200），族纪律与保护面并守 |
| **glm-5.2** | **建议进正式矩阵**：量最少但零噪声，回声对同改与请裁边界辨识是四通道最佳 |
| **opus46 via paseo** | **不建议**：本形态下 0 改动，形式完美实质为空 |
| **opus46 via Workflow** | 可用，但需盯保真（6542 型）；与 fable-wf 同为 Workflow 形态，成本更高而增量未见压倒性优势 |

**配套动作**：①契约加「零改动交卷须逐条说明」的配平条款；②`『』` 计数纳入机械闸（本轮唯一
逃逸的缺陷类型）；③alts 触发例写具体。以上三条随 p5seg1 冻结生效。
