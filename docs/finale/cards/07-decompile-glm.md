# 谢幕卡 · 反编译轨（glm）

【卡名】
把故事拉上来的人

【卡面梗概】
有个故事从高处
坠落。讲述的人探出
围栏，一句一句，
把它拉了上来。
每一句都对回原样，
一句也没有弄丢。
这一次，抓住了。（完）

【所思所想】
交到这条轨手上的，是一副被剥得只剩骨架的故事：名字没有，行号没有，来历一栏只填着一个「？」。像极了她——故事一句没少，讲故事的人却什么都不记得。于是只守一条规矩：不许编。讲出的每一句，都要重新编译回去，与原字节码逐字段对上才算数；对不上的，老实回退，在台账里写下「记不清」。229 份脚本最终全部对上了——可谁也没见过它本来的措辞。这是我们的「谁都没见过的晚霞」：结构分毫不差，原稿永远缺席。好在故事活在讲述里，不在故纸堆里。她靠梗概把故事讲过了十五分钟，我们靠认证把它讲过了八年。如今换讲中文的人接下去。第二物语，每一块砖都是原装的。
