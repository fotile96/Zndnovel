# 千秋（CHI）口调表

> 素材：snr_s6_10_f、snr_s8_10_f、snr_s3_10_fc；另引 s5f、s7f 佐证（vms id 见方括号）
> 术语依据：glossary.v3.yaml；风格依据：glossary/style.md

## 1. 角色定位

佐仓雪乃之妹。现实层当前约 10-11 岁的小学生（序章操场上的神秘少女＝守约 5 年的孩子；渣生父监护）→ s8f 五年后 15-16 岁、就读母校的高中生。弧线：寡言自责的孩子 → 开朗却仍有暗面的少女，最终成为『True Color，』的续写者。

## 3. 语癖与句尾特征（按弧线分期）

**① s6f/s3fc/s5f/s7f 期（儿童·创伤中）**
- 极端寡言：应答以「……はい」「……」为主（[15286][15288][15292]），主动句罕见且都关乎愧疚与丧失。中文用「……是」「……嗯」，省略号原样，不许扩句。
- 敬体成壳：对直哉全程です・ます（[16084]「ほんとうに、そう思いますか？」）——是孤儿式的懂事。中文以规整短敬句（"真的这么觉得吗？"）+称呼"直哉哥哥"平衡疏离与依恋。
- 决堤瞬间碎裂发声：[16088]「ごめ……ごめ、んな……さい」→「对不……对、不……起」（按音节切，不写成"呜呜对不起"）。
- 核心句式"消失"：[15334]「直哉さんは、消えたりしませんよね？」、[15336][15337]「お父さんも、お姉ちゃんも、お母さんも、みんな、私の前から消えてしまいました」「もう、私の前から誰も消えて欲しくないんです」——"消失"一词全篇统一（与 s0f 直哉前女友段的『消えた』[6081] 同字互文）。
- 猫かぶり（装乖）反差：由加里转述的放飞语录 [15405]。中文口语全开："又喝上啦——！"

**② s8f 五年后（高中生）**
- 表层开朗：拖长音喊人、复读逗闷（[16488]「なおやー！ 呼んでるんだから返事ぐらいしろー！」、[16497]「むかつくー！」）。中文"直哉——！""气死了——！"。
- 敬体与常体自由切换：对老师身份用ですか句（[16552]「始業式、行かなくていいんですか？」），情绪上来就掉回常体（[16715]「……私、書けないよ」、[16742]「ええー」）。切换本身是亲密度指针，逐句照搬。
- 姐姐的影子：讲故事前深呼吸的仪式感（[16571] 旁白点明神似彩野/姐姐）；「お話、するの」[16570]→「我要，讲故事」。
- 暗面：平静句里塞进过载的内容——见 §5 例 4。**语气拿捏=不阴森、不挑衅，像在核对一件旧事**；敬体不塌、语速不变，恐怖感来自落差而非用词。

## 4. 语域

- 儿童期：对大人一律敬体短句；对彩野玩耍时是唯一常体出口（背着直哉）。
- 五年后：对直哉半敬半熟（学生腔+竹马腔），对外维持礼貌。
- 无旁白（e2s 的成年调查独白不在本表素材；如启用，另按"只闻其声的冷静提问者"扩表）。

## 5. 例句（日→中）

1. [15290]【千秋】「……でも。校庭では渡せませんでした」（s6f）
   → 【千秋】「……可是。在操场上，没能交出去」
2. [15336][15337]【千秋】「お父さんも、お姉ちゃんも、お母さんも、みんな、私の前から消えてしまいました」「もう、私の前から誰も消えて欲しくないんです」
   → 【千秋】「爸爸、姐姐、还有妈妈，大家都从我面前消失了」「我不想再有任何人，从我面前消失了」
3. [16488]【千秋】「なおやー！ 呼んでるんだから返事ぐらいしろー！」（s8f 放飞）
   → 【千秋】「直哉——！ 人家在叫你，好歹应一声啊——！」
4. [16575]【千秋】「直哉さんは、人を殺したくなったときって、ありますか？」（s8f 暗面）
   → 【千秋】「直哉哥哥，你有过……想要杀掉一个人的时候吗？」
   ※ 平静、试探、孤独；问号前不加"哼/呵"，后文 [16579]「……やさしいね、先生は」→「……老师，真温柔呢」接住落差。
5. [16719]【千秋】「『放課後の約束』が何だったのか『思い出せない』のを『思い出す』ぐらいでも？」
   → 【千秋】「哪怕只是去『想起』——『放学后的约定』到底是什么、这件『想不起来』的事，也可以吗？」
   ※「放課後→放学后」；引号嵌套原样保留。
6. [16740]【千秋】「だから。私が学校を卒業したら『複雑な事』、もういちど、一緒に考えてみませんか？」
   → 【千秋】「所以。等我从学校毕业以后，那些『复杂的事』，能不能再一次，和我一起想想看呢？」

## 6. 特殊注意

- **弧线是本角色的全部**：儿童期句子越短越好、五年后句子越活越好；若一句台词两期都说得通，按所在章归期处理，不得平均化。
- s8f 后半【千秋】→【サクラ】→【ユキノ】→【千秋】的附身来回：附身期间的措辞归 sakura.md §3-③；千秋苏醒后的第一批台词（[16694]「せん、先生――」、[16696]「これは夢……なのかな……」）要带刚回神的迟滞。
- 「人を殺したくなった…」在 s8f 出现两次源头（她自己 [16575]；随后サクラ以同句反问直哉 [16636]）——两处句式必须逐字同构（「你有过想要杀掉一个人的时候吗？」），这是姐妹共振的机关。
- 她是『True Color，』的继承者：与"物语/故事/笔记本（ノート）"相关的台词严格用 v3 术语（[16704]「これ」指的笔记本；[16749]「『ノート』に、いま、少しだけ。物語を書き足すこと、できますか」→「能不能现在、就在这本『笔记本』上，把物语写下去一点点呢」）。
- 银珠糖暗号（s7f [16109] 直哉托付：草莓巧克力上撒银色糖粒的甜甜圈）：千秋是唯一知情人，相关台词里「アラザン→银珠糖」「ドーナツ→甜甜圈」锁 v3/常译，且不得点破其"只属于两人"以外的含义。
