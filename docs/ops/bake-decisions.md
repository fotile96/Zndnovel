# 烤字回填：已定裁决台账

> 每条都是**用户看过实物之后**做的决定。记在这里，是因为这些决定的理由多半来自
> 肉眼观感与取舍，事后从代码里读不出来——而代码只留下结果。
>

> **正确的 PNG + 版面规格**为止。规格快照在 `docs/ops/bake-specs/`。

⚠ **C8 暴露的闸缺口**：这个错误能安静住这么久，是因为 **C5 那道重建验证闸只看
「原图确无文字处」**——它守的是背景，从不看字本身的颜色。一道闸守不到的地方，
就是错误能安静住下来的地方。现已由 `tests/test_bake_card.py` 第 9 组补上。

⚠ **C8 的两条方法教训**（都被真实数据打过脸）：
1. **均值会把重建偏差读成物理现象。** 初测用均值，看到 d=5 处 delta 仍有 −13，
   判成「宽发光长尾」。实际那是 `reconstruct_background` 在文字密的卡上偏亮
   （干净像素少、块靠邻块补）导致的少数像素偏差。换中位数后远场基线归零，
   真实衰减只有约 2px：α(0)=0.95、α(1)=0.36、α(2)=0.03、d≥3 为 0。
   **那圈「晕」就是「有颜色的字」的抗锯齿边**，不需要另加距离场——把字色改对，
   边缘自然就对。
2. **逐卡估计值出现分组时，先怀疑估计量。** 取样门槛 0.92 时逐卡 R 值呈**双峰**
   （25/24），看着像「卡片分两种字色」。逐档扫下来那是门槛的边界效应：
   0.85→σ3.15、**0.92→σ4.80 双峰**、0.95→σ2.97、**0.97→σ2.18 单峰**、0.99→σ2.97
   （样本掉到 14 反弹）。取 0.97，且其结果与另一条独立证据（全库「最暗像素」
   普查落在 56–60）吻合。

✅ **C8 顺带证死了一件事**：把字色改对之后，霞鹜文楷烤出来的字芯仍与原图差 42.3，
而思源黑体（Regular／Medium 皆然）**逐通道相等，色距 0.0**。原因是霞鹜文楷在
9–11px 下笔画细到**没有一个像素达到满覆盖**，纯字色根本不会出现在产物里。
即「字色取对了」与「取对了能落到像素上」是两件事，后者取决于字体。

⚠ **C5 的余量提示**：阈值 60 与实测上限 52 之间只隔 8。此后若卡面素材或字体变动使 `max_diff` 上移，
这道闸会先于观感失效之前报警——**这是它该有的行为**，别为了让它不响而抬阈值。

RGBA 上**只按 alpha 通道判非零**——RGB 差到 255 而 alpha 相同时它照样返回 `None`。
「盒外一个像素不动」这类断言因此**永远绿**，而那正是它要守的东西。实测该 difference
的 extrema 是 `((0,255),(0,255),(0,255),(0,0))`、`getbbox()` 仍是 None，逐像素直接比
却有 16788 个不同。已改为 `tests/conftest.py` 的 `diff_bbox()`（逐通道求包围盒再并）。
**模式框那批也用过同一写法**，改判据后重验：英文确实一个像素没动，结论不变，
但先前那条测试是假绿。

⚠ **另一处被它掩盖的真错误**：缩略图字幕的落点，`bb` 是在草稿图上以 (10,10) 为原点
量的，反推绘制原点时那个 10 被减了两次——整块字高了 8px、右缘差 10px，而**产物看上去
只是"位置略高"**，不像出错。

## 2026-09-01 裁决：孪生态重建——清掉擦不掉的那几粒旧墨（E23）

E22 落地后用户反馈：「成品图内还有微量青色像素 artifact，标题界面如极力辨认仍可见」。

**为什么之前清不掉。** 那几粒旧墨压在英文的发光足迹里（离英文字芯 <5px），按 E5 那条
距离判据一律不许动——擦掉会在英文的晕上豁个口。嵌中文时它们被新墨的晕淹掉看不见，
**改成只擦不写后就孤零零露在英文底下**。宽限额度的理由消失了，额度本身却还留着。

**解法：孪生态。** 这六张每张都含两个状态上下叠放，而**上半的暗态是纯英文、不含假名**
——那就是一份现成的「只有保留层」的地面真值，比距离判据硬得多：判据只知道「这里离
英文近，可能有晕」，孪生态直接给出「这里的英文晕到底是多少」。

实测支撑（`tools/bake_mask.py` 的 `plan(twin=…)`，参数逐张记在数据行的 `twin` 字段）：

| 事实 | 实测 |
|---|---|
| 两态几何是否重合 | 暗态非透明足迹在亮态里的重叠 **98.4–100%**，Δy 为整数 |
| 两态差在哪 | 只差**配色**：暗态晕 `(136,121,235)` ↔ 亮态晕 `(33,32,253)`；alpha 差分布众数 0 |
| 污染有多远 | 「亮态 α − 孪生 α」按离旧墨字芯分箱：d=0/1/2/3 中位 255/123/17/3，**d≥4 中位 0、p95 1** |

最后一行是关键：**远处两态逐字节相同**，这既证明孪生是可用的真值，又排除了「两态本来
就一强一弱」——真有系统性差异的话远处不会归零，那样按超出量做减法会把英文的晕一起削掉。

**判据是合成代数，不是阈值调参**：`α = α旧 + α留(1−α旧) ≥ α留`，污染**只会抬高 alpha**。
故「亮态比孪生亮」⟺「这里还有旧墨」，反之不亮就是干净的、不必动。

⚠ **但代数本身不够，还得加一道几何闸。** 起初以为「英文字芯 alpha 拉满 → 超出量恒为
0 → 判据不会选中笔画」，写进测试后**当场挂了**：两态在笔画**边沿**各自舍入会差 4 左右
（远场超出量 p95 虽是 1，极值却有 11），于是 `title_03_a (20,52)` 与 `title_13_a (44,51)`
两粒**纯白满 alpha 的英文笔画**被当成污染改掉。容差挡不住这条尾巴——挡得住的是
`TWIN_NEAR_D=4`（只在旧墨附近重建，取实测超出量归零的那一档）加上「保留层字芯一律
跳过」。⚠ 教训与本文件多条同型：**「代数保证了它不会发生」要写成测试去验，别写成注释。**

**结果**：12 张残留青像素 **0**（此前 3–11／张），重建 46–98 粒／张，改动全部落在晕上、
碰到英文笔画 **0** 粒，成品比地面真值最多亮出 6–11（＝两态量化噪声本身的极值）。
9× 放大目检，字下方原先那片淡蓝雾状残影也一并消失。

**通用性**：`twin` 是 `bake_mask.plan` 的可选参数，凡「同图另有一份不含旧墨的保留层
渲染」的版面都能用。目前只有 title 六张符合——另六张空间分离、本就零残留，单状态，
