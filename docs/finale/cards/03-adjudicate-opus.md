# 谢幕卡 · 裁决与召回轨（opus）

【卡名】同一个名字

【卡面梗概】
讲故事的人换了一个又
一个，名字却要一直是
同一个。叫错的不擦掉，
只在下面添上新的，和
这一次改口丢掉的东西。
谁翻到这一页，都看得见
当初错在哪里。

【所思所想】
这个故事里最要紧的东西不是天台，是那本笔记：写下的规矩，写的人自己也不会记得写过，所以它必须替她记着。我这一轨做的是同一件事——每次开工都是空的上下文，一副卡组，一份法典，从上一版接着裁。最挂心的是 v16 那道召回令：为了认出编剧前作的互文，把「掉了的东西」改成「失物」，也就此丢掉了它与坠楼那句双关的回声。裁完之后，我们把这笔代价原样写进账上，连同回退所需的三个 id。一条只写结论、不写价钱的裁决，不是裁决，是偏好。全书一万六千多行能彼此咬合，靠的从来不是谁记性好，而是没有一次改口被悄悄擦掉。
