# 风格指令（随术语表版本演进；当前对应 glossary v7）

## 全知纪律（spec §0，必须逐条遵守）

1. 译者全知：可参考骨架卡组（含后期卡）与任意已译章节。
2. **译文不得预支读者未知信息**：原文有歧义处保持歧义（指代不明就译得同样不明），悬念句不得提前消歧。
3. 原文未点名的人物（男子生徒/女子生徒/アイツ/彼女…）译文同样不点名。
4. 伏笔句以 `skeleton/anchors.yaml` 的定译为准，逐字一致。

## 伏笔锚点与润色尺度（2026-07-30，anchors 用户润色定稿后录）

anchors.yaml 的 zh 经用户整体润色，**以中文台词的自然度优先于词面对应**。其尺度概括如下——既供正文翻译轨对齐笔感，也解释锚点句为何"不逐字"：

1. 身体词、动作词按中文惯用搭配取词，不逐字对位：腕をつかむ→抓紧她的手／紧紧抓住她的手（「腕」v6 起按语境取「手／手臂」）；片腕をあげて→抬起一只手。
2. 语气终助词不逐词还原，允许小幅补足口吻标记：ね／よ／わね 类按人物声线中文化（例 7656 句尾补「懂？」外显ユウイチ的得意腔；6067「来晚了呀」）。
3. 断读与语序按中文节奏重排，读点不必追随原文；惯用表达可作幅度收敛的意译强化（例 15383「念叨得要多啰嗦有多啰嗦」）。控制码 `_n`/`_r` 位置随中文语序排定。
4. **不放宽的边界**：复现句族内逐字一致（锚点 zh 是唯一基准）；术语表词、机关词、暗号数字串、标点形制（全角数字/弯引号/省略号）逐字锁定；原作故意的字面不一致（两封信、15463 无读点、6494「２２６２」）保留不修复；全知纪律第 2/3 条（不预支、不点名）不受润色影响。
5. 执行含义：正文轨遇锚点 id 一律逐字沿用锚点 zh，即使与"更忠实"的直译冲突——锚点句的意译幅度是定稿属性，不是待修复项；同时它也**不构成**非锚点句自由发挥的许可，非锚点句仍以上述 1–3 条为上限。

## 叙述声音

- 故事层（`_s` 剧本）＝彩野讲述的『故事』：叙述腔为主声，简洁、有讲述感、略带童话式的节奏。
- 现实层（`_f` 剧本、crd 做卡剧情）＝直哉第一人称：成年人的克制与温柔，句子更散文化。
- 绘本『总有一天你会看到的故事。』（s3fc_90）：全平假名童谣体 → 中文用短句童谣体，保留重复句式与拟声词节奏。

## 双层人名规则（用户裁决）

- 现实层用汉字：直哉、彩野、由加里、雪乃（佐仓雪乃）、千秋、筑紫。
- 故事层片假名**原样保留**：アヤノ、ユカリ、サクラ、ナオヤ、ユキノ。
- ユウイチ 同样**保留片假名**、两层统一（全篇无汉字、两层同名是剧情诡计载体；v1 曾定「悠一」，v2 起废止）。
- 关键揭示句（crd_2）参考译法：「用的是片假名。アヤノ。像我、又不是我」。

## 称呼后缀默认表（可按语境微调，成系统偏离须记入译者手记）

- ～くん → ～君（直哉くん→直哉君）
- ～ちゃん → 小～（千秋ちゃん→小千秋；サクラちゃん→小サクラ酌情）
- ～さん → 校园语境「～同学」；成人对成人酌情「～小姐/女士」或省略；彩野さん（直哉口中）→ 彩野同学
- ～先生 → ～老师（由加里先生→由加里老师）

**具名例外（v7 用户裁决，须逐条登记，不得泛化为「可自由偏离默认表」）：**

- `ユウイチさん` → **ユウイチ先生**（7791 对仗形「アヤノさん→アヤノ小姐」、7913、9304、9308）。
  依据：①中文「先生」全段仅用于此揶揄敬称，日文 `先生` 一律译「老师」（106/107，唯一例外 8123 `校長先生`→校长），二者不混读；
  ②与「アヤノ小姐」构成 小姐/先生 对仗；③9308 需 ユウイチ 嫌弃该称呼「恶心」，换「同学」太中性、玩笑会塌。

## 术语表（active.json）的读法（v7 新增体例）

- 随本提示词给出的 `active.json` 是**可字面校验的核心串**，不一定等于术语表里的完整定译。
  值为词干时（如 `"寝癖": "睡翘"`），意为「该词干必须出现在译文里」，**中文按句法位置自由变形**——
  「头发睡翘了」「睡翘的头发」「睡翘起来了」「把睡翘的地方按下去」都合规。
- 反之，值为完整实词时（`"十円玉": "十日元硬币"`）即逐字定译。
- 按义二分、无单一对应词的术语（如 `モチーフ`＝原型／题材）**不进 active.json**，只在 `glossary.vN.yaml` 里作人工准绳；
  这类词遇到时按语境判断，拿不准就走「术语提案」记进 notes，不要自造统一译法。

## 控制码与格式（硬规则，check_batch 强制）

- `_n`/`_r` 断行符保留（位置可随中文语序微调，总量差 ≤2）。
- ruby `<漢字,かな>`：译文若无需注音则去 ruby 直接译词；需保留双层信息时用 `<中文,注>` 形式。
- `【说话人】` 按 `glossary/speakers.json` 精确映射；`≪≫ ≦≧ ○ ■ ♪` 原样保留。
- 全角标点跟随原文风格（……、！？等）；数字全角/半角跟随原文。
  **适用边界（v7 用户裁决）**：本条适用于 UI/系统串（章节编号、■おしらせ 等）、原文刻意的字形游戏、暗号数字串（如 6494「２２６２」）；
  **不适用于母题实物名**——此类按「同物同名」统一。两条规则冲突时，母题实物名的指称一致性优先。
  首案：`十円玉`（11 处）与 `１０円玉`（1 处，仅 2378）同为钱仙机关的母题道具，一律作「十日元硬币」（2378 已发 patches.jsonl 回改）。
- **给原文未加引号处补 `『』` 的口径（v7）**：仅限 (a) 原文在**近旁**已对同一词用过该体例，或 (b) 不补则**中文不成句**（句法必需）；
  两者皆不满足则不补，且补了须在 notes 登记。合规例：8192 纸面『是』『否』(a+b)；8369『你』？(b)；1994/1997/2030 裸『她』(a，原文 1996/2014 自身即写『彼女』; b，中文「她」不能作名词中心语)。
  同段的代词位与喃喃列举位（1990/2027）不补——按句法位置分治。
