### 1. 千秋口中的「彩野さん」→ 彩野姐姐（本批做法）vs forward 既有「彩野同学」（7187）——冲突，需裁决并可能回改

- 本批 id 9020、9023：`【千秋】「直哉さんは、彩野さんと仲が良かったんですよね？」`／`「じゃあ、直哉さんは、彩野さんの事をどう思っていたんですか」`
- 本批处理：作**彩野姐姐**。依据 `glossary/voices/chiaki.md §2` 的称呼表（彩野｜彩野さん｜**彩野姐姐**｜[16562]），且中文里 １１ 岁孩子称 ２３ 岁女性「同学」不成立。
- 冲突：`data/forward.jsonl` 既有一条 **7187**（s1f，儿童期同一场景群）`【千秋】「それで。彩野さんが『お話』を書いていたという事、ですか」` 译作「**彩野同学**」。即同一角色同一时期的同一称呼，两批不一致。
- 请裁决：(a) 采纳口调表，7187 回改为「彩野姐姐」（推荐，只动一条）；(b) 全线改「彩野同学」，则须同步修订 chiaki.md §2 与 [16562] 的例句。
- 附：本批 千秋 对直哉一律「直哉哥哥」（儿童期），与 forward 7162 一致，无冲突。

### 2. 彩野母口中的「ユウイチさん」→ ユウイチ同学（8866）；同场景她另用「ユウイチ君」（8790/8795）——原文自身不一致，未修复

- id 8866：`【お母さん】「実は……。あれは実は、ユウイチさんの家から貰ったんです」`
- id 8790/8795：`「なるほど、オマジナイ、ユウイチ君、ねえ……」`／`「あと、あの子、ユウイチ君と仲が良くて、恋人――あ」`
- 本批处理：`さん` 作**ユウイチ同学**（沿用 forward 8446/8501 サクラ 口中「ユウイチさん→ユウイチ同学」的既有口径），`君` 作**ユウイチ君**。同一段对话里两种称呼并存 = 原文如此，按 style.md「原作故意的字面不一致保留不修复」照搬。
- 明确不适用 v7 具名例外「ユウイチさん→ユウイチ先生」：该例外限アヤノ的揶揄敬称（style.md 列举 7791／7913／9304／9308），且要求「逐条登记，不得泛化」。本处是死者遗属的敬称，语用完全相反。
- 请裁决：是否接受「同一说话人 さん→同学／君→君」的双轨，还是统一为「ユウイチ君」（代价：抹掉 8866 处母亲改用敬称的语用变化）。

### 3. 療養所 → 疗养院（新词，建议登记）

- id 8882：`「あの時はここじゃなくて、療養所に住んでいましたから」`／id 8883：`療養所……。そうだった……。`
- 理由：彩野事故后的居所，s5f／s7f 追述极可能复现；不定口径会在「疗养所／疗养院／康复中心」之间漂移。建议定**疗养院**。

### 4. 形見分け → 分给我们的遗物（8868，建议登记）

- id 8868：`「あの子が亡くなったときに。形見分け……ですね」`
- 本批处理：`算是……分给我们的遗物吧`。中文无「形見分け」的单词对应（「遗物分赠」太术语、太书面，放不进母亲吞吞吐吐的口语里）。
- 关联母题：这条项链（原为戒指）是 s7f「指輪」母题的现实层落点，建议与「ネックレス→项链」「指輪→戒指」一并登记，避免后续章节改口。

### 5. 断片 → 片段（8763）与 UI 词「フラグメント→片段」同形

- id 8763：`『物語』をカードをつかって説明する時はまだよかった。それは『断片』だから。`
- 本批处理：作『**片段**』。原文这里的 `断片` 与游戏模式名 `フラグメント` 本就是同一层比喻（卡片＝故事的碎片），中文同形反而把互文接上了。
- 登记原因：若委员会日后要求 UI 词与正文词分家（例如正文改「碎片」），此处须一并回改。

## batch 59

### 1. 由加里口中的「千秋さん」→ 千秋（与同场景旁白「千秋ちゃん→小千秋」并存）

- id 9065/9072/9075：`【由加里】「…千秋さんは時たま来てるよね、この場所に」`／`「千秋さんはサクラさんの『妹さん』なんだし…」`／`「うん。だからね、千秋さん、…」`
- 本批处理：作**千秋**（不加「小」）。依据 `voices/yukari.md §2` 称呼表：`千秋ちゃん／千秋さん → 小千秋／千秋`，「ちゃん=日常、さん=郑重体贴」。本场景正是她第一次郑重接纳这孩子（当场给出入校许可），さん 是语用标记，不宜与旁白的「小千秋」同化。
- 附带效果：同一段里旁白（直哉视角）一律「小千秋」，由加里台词一律「千秋」，中文读者能直接听出敬重感的差别。这是 forward 里**首次**出现由加里当面称呼千秋，登记以防后续（s3fc [11038][11042] 等）漂移。

### 2. 母题词「含まれる」→ 包含（9135/9162），与既有「登場する→登场」分词

- id 9135：`どうして僕があの物語に『含まれていないのか』`；id 9162：`登場人物として、含まれていればいいのだけれど。`
- 本批处理：`含まれる` 一律作**包含**（『没有被包含进去』／『被包含在里面』），`登場人物` 仍作**登场人物**。
- 依据：forward 既有 9001/9013（`でてこない`／`登場しない`）已译「登场」。原文在同一话题上**换了词**（千秋问的是「出てこない」，直哉转述时改用更疏远的「含まれていない」），中文同样换词才保得住这层退让感。
- 登记原因：s7f/s8f「僕は物語に含まれていたのか」系句族大概率复现，届时须与本批同形。

### 3. 系统串 17016『新しい物語が届きました』→ 新的故事已送达（本批首译，另有 3 条同文待译）

- id 17016：`【■おしらせ】新しい物語が届きました。`。语境＝完成 s2f 后解锁 `library` 的第 2 本页图小说（`cut_nv_2`），故「届く」是实义的"送到"。
- 本批处理：**【■通知】新的故事已送达。** 体例对齐 forward 17002「片段模式：章节１已完结。」的系统书面语。
- 同文未译：**17019（s3fa）／17024（s4fa）／17039（s4fb）**——三条字面完全相同，后续批次请逐字沿用本条，否则同一条通知会出现四种译法。
- 同批 17015 `フラグメントモード：セクション２が終了しました。`→「片段模式：章节２已完结。」，直接沿用 17002 口径，无新增判断。

### 5. 工装观察（W3 假阳性 1 条，本批**未**为讨好脚本改译）

- id 9131：`先生も、僕も。`（jp 宽 14）译作「**老师也是，我也是。**」（宽 18 > 14×1.15=16.1），记 1 条 W3。
- 不改的理由：`voices/naoya.md §3` 明列直哉旁白的**复沓推进**（「一歩、二歩、三歩、四歩。」）「不合并句子」；此句正是 9129/9130 的收束复沓。可过线的写法（「老师和我都是。」宽 14）会把复沓压平。
