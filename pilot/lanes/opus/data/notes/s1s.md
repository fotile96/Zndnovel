## batch 4

### 1. 寝癖 → 睡翘的头发 / 头发睡翘了（**跨轨复现，优先级最高**）
- id 7327、7329、7332、7333、7335、7337、7359、7373（本批 8 处）；另 snr_crd_0 id 198『男子生徒の寝癖がなおらなくて……』、id 202 同段复述
- 建议：名词态**睡翘的头发**、谓语态**头发睡翘了**（不用「呆毛」「乱发」「起床气头发」）
- 理由：这是章节 1 开场唯一的笑点道具，且直哉在 crd_0 向彩野复述『お話』时会再次点名它——两处措辞必须能对上，否则"他复述的是同一个故事"这层关系会散。「呆毛」是二次元圈内语，会戳破 style.md 要求的"彩野在讲故事"这层皮。本批已按上述译法统一。

### 2. 菜单名的拉丁形态需要一条形态判据
- id 6632、6633、7306、7307、17185：『ｌｉｂｒａｒｙ』『ｍｅｍｏｒｙ』『Ｆｒａｇｍｅｎｔ』（全角拉丁）
- 现状：style.md 定「フラグメント→片段、ストーリー→故事」，但这几行原文本身写的就是全角拉丁菜单名，且 batch 1 的 6630 已按原样保留『Ｓｔｏｒｙ』
- 建议：立通则——**片假名形态（フラグメント/ストーリー）中文化，全角拉丁形态（Ｓｔｏｒｙ/Ｆｒａｇｍｅｎｔ/ｌｉｂｒａｒｙ/ｍｅｍｏｒｙ/ｎｏｖｅｌ）原样保留**，因为它对应的是图片轨里烤死的英文按钮
- 理由：同一批系统通知里两种形态都会出现（如 snr_fragment_main 6056 用的是「ストーリーモード」），没有判据就会各批各译；且译成中文后玩家在菜单上找不到对应按钮。

### 3. 『ことば』(7302) → 『话语』
- id 7302：`『さて』と、私は『ことば』を口に出して言う。`
- 建议：**『话语』**，并沿用 batch 2 提案 6 的规则（片假名/引号陌生化 → 中文以『』承担）
- 理由：卡 111「僕の言葉→我的话语」已把「言葉」定为"话语"，而此处是开场白里被引号推远的同一概念（说出口即启动故事），两处宜同词。请一并裁决 batch 2 提案 6 是否立为通则。

### 4. テスト / 小テスト 的两级对应
- id 7368『テストだっけ！？』（本批）；紧邻的 7378『小テストをやるってユカリ先生、言ってた』（下一批）
- 现状：skeleton 卡 2 作「考试」，卡 3 作「小测验」——原文正是 テスト / 小テスト 之分
- 建议：**テスト→考试、小テスト→小测验**，登记为固定对应
- 理由：s1 全章围绕这场古文测验展开，两词交替出现十余次；不定死会出现同一场考试一会儿"考试"一会儿"小测验"的漂移。本批 7368 已按「考试」译。

### 5. ★存疑（非术语）：7374『朝、夏の学校。』的行宽警告
- id 7374：译作「○_n早晨，夏天的学校。」，触发 1 条 W3（18 vs 阈值 16.1）
- 说明：原文只有 6 个假名，任何自然的中文译法都会超 1.15 倍；该行实际只有 9 个汉字，远低于 `cBrStr` 的 24 字硬折行，无溢出风险
- 处理：**保留自然中文，接受该 warn**；若评审希望零 warn，可改「○_n清晨的夏日学校。」（16），但会丢掉原文「朝、」的停顿感

### 3. 先輩 → 前辈？学长／学姐？（★缺口径，本批已按「前辈」落笔）
- id 7431「慌てて先輩に今日は早めに練習切り上げてもらったんだよん」
- 现状：说话人是田径部的女同学，`先輩` 性别不明；中文校园语默认「学长／学姐」需要指定性别，「前辈」则性别中立但带译制腔
- 建议：定为 **前辈**（性别中立、可复用），或规定"性别可判时用学长／学姐，不可判时用前辈"
- 理由：`先輩`／`後輩` 在 s1s 田径部线、s3s 传闻调查线（卡 73「或许是暑假里参加社团活动的孩子经历的」）、e2s 筑紫回访段都会出现，且多数场合性别不明。不先定通则，各批会在「前辈／学长／学姐／师兄」之间漂。

### 4. 国語 → 国语；通知表 → 成绩单（与「現国→现代文」「古文」配套）

- 建议：`国語` → **国语**（保留日本学科名，不换成大陆的「语文」）；`通知表` → **成绩单**（不用「通知书」「成绩通知单」）
- 理由：与 batch 6 提案 1（`現国→现代文`）、batch 4 提案 4（`テスト→考试／小テスト→小测验`）同属学科・考试词族。此处若把「国語」改成「语文」，会与由加里所教的「古文／现代文」体系割裂（日本学制下三者是同一科的分支）。`通知表` 取「成绩单」是因为下一句 7391 ユウイチ立刻反攻「算数とか理科とか」，需要一个能挂科目的容器词。

### 5. ★存疑（全知纪律敏感）：若年性なんとか（7494）的模糊度
- id 7494「うーむ。もしかしてコレが若年性なんとかってヤツなのかなあ……。」
- 本批译法：「唔——。难道说，这就是所谓的年轻型什么什么症吗……。」
- 说明：原文用「なんとか」把病名糊掉（指向`若年性認知症`），这是**故事层アヤノ的玩笑**，同时是**现实层彩野病情的暗伏**。译文必须同样糊住：不得出现「阿尔茨海默」「认知症」「痴呆」等实词，也不宜过度玩笑化（「老年痴呆」会既破功又走味）。
- 待裁决：是否保留末尾的「症」字。保留则更像一个病名（伏笔更清晰），去掉（「年轻型什么什么」）则更贴原文的含混。本批选了保留，**建议人工复核这一处的伏笔强度**。

### 2. 腕を組む → 抱起胳膊（与 v6「腕」召回令的边界）

### 4. 犹疑感叹词族的中文对应表（本批 22 行里出现 6 处，建议成表）
- id 7468 `うーむ`、7469 `うーん`、7481 `えーと`、7482 `ええー`＋`よー`、7483 `あー`、7487 `うー`

### 5. ★存疑（非术语，请人工复核）：7486 的对偶句节奏
- id 7486「してたと言えば約束していたような気もするし、していないかといえばやっぱりそんな気もする……。」
- 本批译法：「要说约过吧，好像是约过的；要说没约吧，又果然觉得好像是没约……。」
- 说明：原文是"两头都觉得对"的自我拉锯，后半的 `やっぱりそんな気もする` 省略了宾语（"也觉得是那样"）。译文补出了"好像是没约"以求中文可读，但**补出宾语等于替她把话说满了一点**——原文的含混度略高于译文。
- 待裁决：是否改回同样含混的「要说没约吧，又果然也觉得是那么回事……。」我倾向保留现译（可读性优先），但这一处的"补"值得复核，因为她"记不清放学后的约定"正是章节 1 的机关句（关键词卡 131「和那孩子见面的约定」），含混度本身是伏笔材料。
