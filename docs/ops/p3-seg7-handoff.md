### 4.3 ★★ 开篇 5675–5689 与 e2f 开篇 4784–4794 是**同一段文字的两个版本**

这是本段最容易被漏掉、也最不可挽回的一处。两边逐行对照：

| | **e2s 5675–5689（崩解版）** | **e2f 4784–4794（完好版）** |
|---|---|---|
| 音乐传来 | `遠くから音楽が聞こえてくる` | `どこからか音楽が聞こえてくる` |
| 回想 | `……私は思い出す。` | 同 |
| 认出 | `帰りの歌、だ。` ／ `『戻らないと』。` | 同 |
| 侧耳 | `耳を澄まさないと。` ／ `言葉を聞かないと。` | 同 |
| **きく** | `曲をきかないと。`→`曲を訊かないと。`→`曲を聴かないと。` **同音异字散开三次** | `曲を聴かないと。` **一次落定** |
| **綴る** | `言葉を書かないと`→`言葉を`→`言葉を書く`→**`言葉を綴らな`（断在半途）** | `言葉を綴らないと。`＋`――物語を。`＋`物語を、綴らないと。` |

也就是说：**e2s 那版是正在崩解的（雪乃弥留之际的意识），e2f 那版是完好的。**

⚠ **而完好那版已经有定译**——`4793`／`4794` 是**锚点**：

```
4793  ――物語を。          → ――故事。
4794  物語を、綴らないと。   → 得把故事，续写下去才行。
```

**你会先做 e2s（b167）、后做 e2f（b170）**，所以必须**反着来**：先去读锚点里那两句的定译，再拿它的措辞去构造 e2s 那一版的崩解形，让读者读到 e2f 时能认出「这是刚才那段话，只是那时它散了」。

- `きく` 的三个汉字（聞/訊/聴）在中文里没有同音异形的现成对应。**允许换载体**（例如用近音字、或用同一个「听」字配不同的字造成滑动），但**必须让「同一件事被反复换字写」这个动作看得见**——它是意识在失焦的唯一证据。
- `言葉を綴らな` 断在助词前，**中文也要断在不成句的地方**，不要补全。
- 这一族**不会被任何机械闸抓到**（不是复现句、jp 不全等、不触 W3/W4），只能靠这条交接。
